Ветка `front/v2-design` от `origin/front/final` (2f590c6d), затем слит `origin/front/final` 710a9adf (контракт API 1.1.0, tech.md v5).
Скриншоты: `before/` (сняты с нетронутого 2f590c6d) и `after/`, имена `NN-роль-экран-ширина.png`, 1920×1080 и 1366×768; в каждой папке есть `audit.json` (консоль, горизонтальный скролл, обрезанный текст, CLS).
