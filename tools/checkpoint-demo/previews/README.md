# previews

Кадры камер для стены мока (`GET /api/cameras/{id}/preview`, файл `cam-<id>.jpg`, 16:9).
Это синтетические иллюстрации: кадры, сгенерированные в ChatGPT Images, и кадрированные иллюстрации фронта
(`frontend/public/fixtures`), на каждом подпись «СИНТЕТИЧЕСКИЙ КАДР · иллюстрация».
Не запись с камер и не результат нейросети. Свой кадр: положите `cam-<id>.jpg` и перезапустите мок.
Нет файла или камера без наблюдения — `preview_url: null`.
