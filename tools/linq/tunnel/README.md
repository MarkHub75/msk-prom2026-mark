# Туннель к LinQ через ноутбук Матвея

Прямого OpenVPN на этой машине нет (см. `docs/linq/VPN_SETUP.md`). Все сервисы LinQ
(`10.0.114.0/24`) доступны только через SSH на ноутбук Матвея, где поднят OpenVPN.

| Локально | Куда | Что |
|---|---|---|
| `127.0.0.1:8888` | `hackathon.lin-q.ru:80` | JupyterHub |
| `127.0.0.1:5672` | `10.0.114.30:5672` | RabbitMQ AMQP — API TPU |
| `127.0.0.1:15672` | `10.0.114.30:15672` | RabbitMQ management |

- `Connect-LinQ.cmd` — поднять (или перезапустить, если набор пробросов изменился) и открыть Jupyter.
- `Stop-LinQ.cmd` — остановить только туннель (Happ не трогается).
- `LinQ.ps1 -Action Status` — проверить.

Новый сервис в `10.0.114.0/24` — добавить строку в `$Forwards` в `LinQ.ps1`, а не ходить в подсеть напрямую.

Условия: ноутбук Матвея включён, в той же сети и с OpenVPN; ключ `%USERPROFILE%\.ssh\linq_matvey`
(публичная часть добавлена в его `authorized_keys`). Адрес по умолчанию `sl1m@192.168.1.31`,
переопределяется переменной окружения `LINQ_TUNNEL_REMOTE`. Лог ошибок ssh: `%LOCALAPPDATA%\linq-tunnel\`.
