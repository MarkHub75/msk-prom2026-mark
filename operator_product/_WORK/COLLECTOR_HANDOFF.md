## Решения, которые должны пережить литературную редактуру

Основной продукт — проверяемый видеоэпизод с происхождением, человеческим решением/неизвестностью и историей; мера по процессу/причине, а не task на каждый кадр. Дежурный→мастер — условная карта A; разрешённый локальный warning→later review — B; без выхода/полезного окна — async detection/review. Universal review-before-notify снят W2, F107/F108/F139. Никакого обещания защитного останова/предотвращения браузером.

ACK/assignment/истинность/действие/verification различны. FindFace2.2.1 auto-ACK/overflow — только Alarm Monitor; Completed после первого комментария — обработка, не мера. Внешние state/origin/mapping сохраняются, system не human. Политика может не требовать второго verifier каждого мелкого действия; not_required не verified. Source ID/system retry не новый реальный эпизод; grouping разных эпизодов решает violation_methods.

Privacy: F117 сохраняет DPA unblurred cloud QA/training exception, optional edge masking, contractors и termination30days как отдельный scope. F118/F119/F120 — deployment-only/site models/refinement/общие updates неоднозначны; не выбирать уверенный пересказ «всё на edge/после go-live не учится». Original/derived/overlay/export/attachment/training permissions отдельны. No recognition/blur не полная анонимность; badge недостаточен; worker voice не получен. Право РФ/retention не выводятся из иностранного guidance/шаблона.

Отзывы F114 — self-report G2, Amanda invite, Syed/Ariana Organic; invite не доказанная оплата. Ergonomics false alerts не PPE-качество РФ. Carlex/UAW F121 vendor-curated, не прямая позиция рабочего/соглашение. Browser unavailable F113 — ограничение исследования, не дефект Protex. Скриншотов продукта/кликов/UX-аудита/доступности конкурента нет; DPA_P06.png — страница документа.

Feedback raw customer/vendor/curated отдельно, спор/insufficient сохраняются. Без независимого архива miss_candidate, без recall; sampled-alert Accuracy API не общая accuracy методика.
