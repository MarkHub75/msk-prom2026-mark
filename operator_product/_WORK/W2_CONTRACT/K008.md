# K008 — минимальный product→architecture контракт

23.10.2026 Europe/Moscow. Предлагаемый статус: **сужена применимость; контракт/fallback определён, реальные входы и LinQ открыты**. [K003.md](K003.md) задаёт независимую семантику действий. Здесь W2-CONTRACT-F07/F08 — **INF/HYP требования**, не доступный API, не проведённая интеграция. Основания: W1-U06-F03/F04; U07-F02/F03/F06/F10; U08-F02/F08; U13-F03; U14-F01/F03/F06; U17-F03–F06; дополнительный DOC W2-CONTRACT-F04 (схема snapshot одного VMS, не LinQ).

## Поля, истина и деградация [W2-CONTRACT-F07, INF]

M = нужен для достоверной карточки/происхождения; C = нужен лишь для обещанной функции. Поля не следует фабриковать ради M: при отсутствии честно отключается соответствующее обещание, а ingest сохраняет неполный кандидат с диагностикой.

| Поле/функция | Кто даёт источник истины; что пока неизвестно | Missing/недоступность → видимое UI и предел действия |
|---|---|---|
| M event_id + schema_version + source_event_id/idempotency_key | Генератор/адаптер событий; реальный формат неизвестен | Нет стабильного source ID → локальный receipt_id и «идентичность источника не подтверждена»; не обещать cross-system dedup и сквозной trace |
| M source_system/camera_id/site/area + mapping_version | Реестр источников/интегратор, не свободный текст модели | Камера/место неизвестны → «источник не сопоставлен», нельзя направлять на конкретный участок по догадке; без персонального ID по умолчанию |
| M input_ref + frame/PTS/range + source_time_basis | Ingest/VMS/файл, реальное соответствие clocks/архива неизвестно | Нет привязки к исходному материалу → «материал события недоступен», review insufficient; live отдельной кнопкой/подписью |
| M observed_start/end (end nullable), source_clock_id, timezone/offset, clock_sync_status/uncertainty | Камера/VMS/ingest согласно явной семантике | Неизвестный offset → сохранить raw timestamp и basis, не показывать выдуманное локальное время/длительность/latency; «время источника не сопоставлено» |
| M received_at + generated_at + last_updated_at/revision | Наш сервер отмечает собственные receipt/update; upstream generation — отдельно | Нет upstream generated → можно измерить лишь наш приём/обработку; arrival time не заменяет момент нарушения |
| M mode live/replay/stored_result + replay_session_id, processed_at | Драйвер источника/job metadata, не надпись оператора | Неизвестный режим → «режим происхождения не подтверждён»; не говорить real-time. Replay хранит исходную и текущую processing timeline |
| M machine_result/event_type + rule_id/version + model/artifact_ref | violation_methods/model runtime + rule registry | Неизвестная версия → «версия не получена», не воспроизводить обещание точного rerun; базовое правило без фильтра результата не означает нарушение (Macroscop counterexample) |
| C geometry/overlay + coordinate_space/resolution + view_revision | Rule registry и preprocessing, привязка к кадру | При разных ракурсах/размерах без mapping overlay скрыть; показать исходный кадр. Нет geometry → читаемое правило, без ложной зоны |
| C media.frame/clip_ref, status pending/ready/failed/not_recorded/expired/forbidden, range, gaps, created_at, origin | VMS/clip service; наличие pre/post и архива неизвестно | Pending → кадр+«клип готовится» без запрета предварительного warning; failed/no archive → «доступен только кадр»; нельзя принуждать проверять длительность/до-после без материала |
| C media.access_scope + allowed_actions/view/export + expiry, original/masked/overlay rendition | Auth/media owner; ссылка может быть доступна серверу и недоступна получателю | Forbidden ≠ отсутствует; «нет прав», кнопка запроса разрешённого доступа/insufficient; не копировать автоматически в мессенджер, export выключен |
| M control_health per camera/decode/inference/event/media + test_origin + checked_at/last_good_at | Узел соответствующего участка пути; серверный test_origin обязателен для утверждения пути | «Поток есть, аналитика недоступна»; unknown отдельно от failed; тест ноутбука не подтверждает сеть сервера/LinQ |
| C freshness/policy_id + current_hazard evidence/as_of/valid_until | Архитектура+policy, допустимый возраст не установлен | Поздний event видим с возрастом/историческим временем; current hazard unknown/stale; оперативное действие нельзя обосновать одним старым кадром |
| M review/origin/revision, owner/acceptance, delivery attempts, measure refs | Наш журнал/согласованная внешняя система | Отсутствие ACK → «не принято»/unknown; system auto-ACK отдельно; несколько оценок не затираются; кнопки требуют server revision |
| C LinQ job_ref + input_ref + model_ref + result_ref + execution_artifact_ref + processing times/environment | linq_platform/video_architecture должны дать реальный доказательный артефакт, его форма неизвестна | Нет trace → «исполнение на LinQ не подтверждено»; сохранённый результат подписан. UI/CPU/RTX результат не закрывает обязательное условие |
| C external_ticket/ref + integration_source/mapping version | Реально доступный тестовый приёмник/HSE-система | JSON/export ≠ connector; HTTP acceptance ≠ человек/мера; retry status виден отдельно |

`last_good_at` и health имеют область пути и возраст; глобальный зелёный health запрещён, если известна лишь живая картинка. Секреты камеры/токены в payload карточки, export/trace и экран защиты не попадают. Медиа может содержать лицо в оригинале даже при masked thumbnail; нужны права на каждую rendition. Респиратор может исчезнуть после face mask: такую картинку нельзя использовать для вынужденного подтверждения.

Межпакетное уточнение принято: [EXPERIENCE K006.md](../W2_EXPERIENCE/K006.md), W2-EXPERIENCE-S04/F06 — документальная причина разделять original и derived; F11 — авторский data-flow, а не обязательная схема хранения. Поэтому к media ref добавить `rendition_type`, `masking_version/status`, `original_ref?`, раздельные `view_original/export/attach` permissions; к экспорту — derivative/recipient/channel/purpose и автора. Для внешнего сообщения default проекта — minimal text+authorized link при разрешённом канале; attachment требует отдельного права. Отзыв доступа к ссылке не удаляет уже сделанные внешние копии. Права review не дают training права; `eligible_for_curation`/`approved_for_training` отдельны. Нельзя обещать cascade deletion NVR/cache/messenger/dataset или фиксированный retention без реального механизма/политики.

Состав input LinQ (unmasked/derived), место temp/cache/логов и получатель — открытый processing-path контракт, а не доказанная локальность. Protex F07–F09 показывают unresolved scope разных публичных обещаний, поэтому «всё анонимно на edge» и auto-refinement не переносятся на наш продукт. Videoless metadata без изображения — отдельный маршрут: зарегистрировать/маршрутизировать кандидат можно, визуальное подтверждение нельзя обещать.

Для сводки добавить только при её реализации `cohort_scope`, `observed_range`, `review_snapshot_at`, `selection_policy`, `camera×rule×version health intervals`, `measure_applied_at?`; основания и определения — [PROCESS K009.md](../W2_PROCESS/K009.md), авторский словарь на W2-PROCESS-F02 и W1-U11. Интервалы off/fault/unknown различны; camera-hours не exposure. Это поля для честного списка/чисел, не требование строить BI или вычислять все показатели в минимуме.

## Clock domains [W2-CONTRACT-F08, INF]

| Домен | Что измеряет | Допустимая арифметика |
|---|---|---|
| Camera/recording/source wall clock | Время наблюдаемого материала | Только после установленного offset/timezone/sync; Macroscop webhook local server time не camera time |
| File media PTS / source timeline | Положение кадра в replay/архиве | Длительность внутри того же timeline; привязка к wall clock отдельным mapping, нельзя принять PTS за Unix time |
| Ingest/server wall+monotonic | Приём/построение/изменение события | Локальные длительности на monotonic одного процесса; wall clock для аудита, после скачка часов negative latency не «исправлять» скрыто |
| Remote inference/job clock | Начало/конец job и результат | Duration если контур её достоверно возвращает; межконтурная latency только при sync/известной неопределённости |
| Media service | Клип готов/время создания/доступность | Время готовности отдельно от event occurred/notification sent |
| Device/client human action | Локальный tap и server accepted | Client tap при offline ≠ server ACK. Для серверной истории время записи; asserted human time отдельно, не маскировать backdate |

В UI достаточно двух строк «наблюдение: … (источник/режим)» и «получено: …», плюс статус материала и давность текущего состояния. Точность timestamp и обработка смены timezone → video_architecture. Replay может демонстрировать скорость обработки материала, но не заводской end-to-end latency с момента наблюдения. Времена доставки/человеческой реакции/действия/проверки не объединяются.

## Шесть сценариев границы

| Случай | Поведение / что снимается |
|---|---|
| Event раньше клипа | Карточка+доступный кадр+pending; review допускает insufficient; разрешённый предварительный warning не ждёт сборку; show readiness отдельно |
| Нет архива/только кадр | Безклиповый маршрут K010; не обещать контекст, длительность, поиск missed-event по архиву или recall |
| Late event | Historical/replay/stale label; не подменять свежим live; приоритетный оперативный маршрут только по согласованной свежести |
| Камера сдвинулась | view_revision mismatch/«зона требует проверки»; правило нельзя считать готовым до перепроверки; живой decode не решает |
| Повтор transport/system retry | Один source_event/operation с attempts; новые реальныe эпизоды отдельны; unknown dedup не скрывает поток без счётчика |
| Live есть, LinQ недоступен | camera ok / inference unavailable; старое видео/result as_of; новые детекции не имитируются; LinQ requirement открыт |

## Адресная передача и закрытие

→ video_architecture: получить один реальный payload и материал, source_time basis, place of connectivity test, независимые health/clip states, idempotency, auth expiry, UI server revision; предложить fixture каждого из шести сценариев. → violation_methods: устойчивый episode ID, event type/result filter, start/end semantics, coordinate transform, view change invalidation. → evaluation: различить event/system/human/media clocks, lateness/sync uncertainty, missing coverage и replay; не вычислять recall из тревог. → linq_platform: какой конкретный доступный артефакт связывает input/model/job/result с фактическим LinQ; здесь артефакт не изобретён.

K008 не закрыт как реальная интеграция: отсутствуют full case, payload, media rights, LinQ execution artifact. Предложение готово к согласованию и опровергается получением frame-only/late/no rights/no trace: в каждом случае уменьшается функция/маршрут, а не скрывается ограничение. Для проверки достаточно доступного одного разрешённого источника и одного job, затем fixtures отказов; это предложенный тест, не выполненный benchmark.
