# Google opens TorchTPU to run native PyTorch workloads on TPUs

TechEnclave News Desk

The release includes a vLLM serving backend; Ironwood is the recommended TPU hardware, with older generations experimental.

Image vLLM / Inferact and Google

Google has open-sourced TorchTPU, its stack for running PyTorch workloads on Tensor Processing Units. PyTorch is a widely used framework for building and running machine-learning models; TPUs are Google's specialised AI processors. The release makes TPUs a native target rather than requiring a separate model implementation.

Developed with Meta's PyTorch team, TorchTPU supports familiar APIs, eager-mode debugging and compilation through torch.compile. Google also describes integrations with Hugging Face and serving tools, giving developers a route to train and deploy models while retaining more of their existing software workflow.

Inferact and Google separately released vllm-torchtpu, a plugin for the open-source vLLM model server. It keeps vLLM's scheduler, API server and model definitions while providing TPU-specific execution and kernels underneath. --------------------------------------------------------------------------------
