# Presentation Craft — raster-slide проверка

Использован штатный Presentation Craft 1.0.0 и image-slide precedent `cinematic-ppt-v1/final-production` Frontend Hackathon OS. Story contract отделён от адаптера. Слайды созданы как PNG; служебный HTML только показывает одно готовое изображение для измерений. Выступление проводится из PPTX.

Пострендерный `capture.mjs` выполнен без изменения OS: **32 captures**, все 8 слайдов при 1920×1080 и 1280×720, normal/reduced. SHA источников стабильны, runtime errors — 0; все 32 source records совпадают по hash. [Исходный отчёт](evidence/craft/report.json) сохранён без исправления findings.

41 finding:

- 32 `missing-assertion`: DOM probe не читает русский текст внутри PNG. Это ограничение raster workflow; скрытый DOM-текст для искусственного PASS не добавлялся.
- 8 `craft-review`: advisory для человека по иерархии, композиции и смыслу.
- 1 `rubric-unknown`: отдельный официальный оценочный регламент не предоставлен; критерии жюри не выдуманы.

Точная типографика проверена отдельно: coverage всех символов Golos Text, границы каждого текстового фрагмента, единый canvas 1920×1080 и фактические численные значения из первичных JSON. Два неподдерживаемых символа и обрезанный заголовок UI-фрагмента исправлены до окончательного capture. [Content receipt](evidence/content-report.json), [composition и crop provenance](evidence/composition.json).

Независимый визуальный осмотр всех восьми финальных PNG на 720p выполнен после обновления frontend до `8161719d`: [отчёт](research/independent-visual-review.md). Критических дефектов не осталось. Микротекст внутри обзорных снимков приложения не предназначен для чтения с проектора; ключевой смысл и оговорки вынесены отдельной крупной типографикой. Новые снимки не выдаются за измерение CV.

PowerPoint 16.0 открыл и экспортировал все 8 слайдов. В PPTX встроены точные исходные PNG; по одному полноразмерному изображению на слайд, заметки совпадают. Средняя абсолютная разница каналов обратного PowerPoint-рендера менее 0,25 из 255 на каждом слайде: небольшая растровая интерполяция. Отдельный PDF повторно отрендерен и совпал с исходными PNG пиксель в пиксель. [PPTX receipt](evidence/exports/report.json), [PDF receipt](evidence/pdf-report.json).
