## Факты

**W2-09-F01 — прочитанная документация S01§3.1.** Indoor/outdoor videos разных людей/мест/времени screen every several frames через MTCNN, оставляя изображения с лицом. LabelMe behavior bbox покрывает **лицо и связанные объекты**, labels `smoking`,`calling`,`normal`. Отдельно boxes `hand`,`cigarette`,`phone`; face coordinates получены MTCNN, не ручной face разметкой. Это не whole-person bbox и не temporal interval. Selection bias: невидимое/отвёрнутое лицо отсеивается, что ограничивает дальнюю/верхнюю камеру.

**W2-09-F02 — авторские числа S01, не локальный count.** Train10,461frames; behavior4516smoking/3968calling/1977normal; object9861hand/6197cigarette/4873phone. Test1167images из другихvideos/webpages. `Different videos` не задаёт документированный subject/camera/session holdout; manifests/IDs/payload не получены. Авторы признают трудность actual samples gas stations/libraries/petrochemical/coal environments; Fig6web examples не target validation. СтатьяCCBY4.0 не устанавливает лицензию неприсланных данных.

**W2-09-F03 — DataAvailability S01.** Данные доступны corresponding author upon reasonable request. Письмо не отправлялось. В полномPDF нет public dataset download/repository URL. Адресный запрос: original images/LabelMe labels, map, source-video IDs, splits, explicit data licence, demo/redistribution rights. Не найденная ссылка не доказывает отсутствия любого author mirror.

**W2-09-F04 — выполненное измерение S02/S03.** Все1120JPG декодированы Pillow`load()`, все250×250pixels. SHA256 decoded RGB не нашёл exact pixel duplicate groups. Это не perceptual/near-duplicate/person overlap audit и не доказательство split independence. Исходные716train/180validation/224test сохранены; filename labels image-level.

**W2-09-F05 — выборочное наблюдение S03.** Среди40negative thumbnails: `notsmoking_0091.jpg` — телефон около лица; `notsmoking_0053.jpg` — телефон в руках; `notsmoking_0120.jpg` — ингалятор у рта; `notsmoking_0041.jpg` — рука у лица, действие неоднозначно. Есть крупные портреты/студийные/web фотографии. Это наши proposed visual tags, не source annotations. Drinking/eating по W1queries не считаются подтверждёнными здесь. Выборка не устанавливает доли confusers или false-positive rate; исходныйpositive класс не меняется автоматически по статичному фото.
