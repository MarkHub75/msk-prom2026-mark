# Передача автору datasets

Collector завершает offline сборку после двух замороженных волн. Входы: полностью прочитаны Context-prompt.md, prompt-datasets.md, PLAN/RUN_STATE, downstream задание, все 15 W1/все 15 W2, исходная CRITIC и ключевые сохранённые первичные artifacts. Нового сетевого исследования, третьей волны, training/accuracy/LinQ benchmark нет. Финальные аналитические роли идут последовательно; отдельного аудитора не создавать.

Доказательная база: [SOURCES.md](../SOURCES.md) —48 S-ID; [RAW_FACTS.md](../RAW_FACTS.md) —102 F-ID; [OPEN_QUESTIONS.md](../OPEN_QUESTIONS.md) —20 Q-ID и 33 E-ID; [CRITIC.md](../CRITIC.md) — исходная история K001–K015 и отдельное дополнение после W2. [ID_MAP.md](ID_MAP.md) сопоставляет 157 source aliases/235 fact aliases и веточные вопросы/программы. У всех чисел сохранять scope: published claim, manifest, actual parsed annotation, decoded pixels, targeted visual review или proposed experiment.

## Основная доказательная картина

У команды есть конкретные внешние artifacts и уже локализованные проблемы, но пока нет полного case/organizer data. Значение research — выбрать роль источника и следующий gate, а не назначить один набор универсальным победителем. Ближе всего к заводской камере SFCHD; для реального replay полезен Önal; для широких object/body-part donors полезен SH17. Для industrial respirator state и smoking near flammable materials готового полного event GT не установлено. Это ограниченный результат поиска, не заявление, что данных вообще не существует.

Авторский текст должен сначала объяснить эту картину, затем раскрывать сильные решения/контрпримеры. Подробные source cards/counts остаются в RAW; человеческий отчёт не обязан повторить все 132 scale groups. Он обязан сохранить важные условия и точные ссылки/F-ID рядом с выводами. Нормальный русский связный язык, без слитной прозы из служебных журналов. Нельзя размыть различия document/claim/our check/inference/proposed/unknown.

## Практическая программа и принятие organizer data

В тексте отчёта объяснить очередность E015→E001/E002/E003→E004/E005→E006/E007→E008, с E014 parallel по конкретным действиям. E012/E013 закрывают target event gaps, E010/E011 optional gated branches. E016 — full selected artifact audit только после выбора; не качать все найденные наборы. E017 — agreement/unknown, E018 — manifest roundtrip. E019–E033 уже выполнены строго в указанном bounded scope, их не смешивать с предложенными программами.

Manifest F101 обязан сохранять source/version/original IDs/bytes and pixel hashes, original annotation/bbox/unit, nullable supplied groups отдельно от inferred groups/evidence, reversible class mapping/transform history, coverage/visibility/observed state/relation, usage role/reason/quarantine и license layers/actions. F102 — готовая процедура organizer intake. Нельзя выдумывать camera/session IDs, число кадров или качество будущих данных. Locked target holdout выделяется до external merge; calibration/threshold tuning только development. Conditional merge требует geometry/semantic/coverage/rights/overlap gates. Crop не создаёт потерянную оптику,640 не установленный LinQ input, успешный parsing не качество модели.

## Freeze и ограничения

Сборщик не менял frozen W1/W2 и исходный текст критик и. Нет нового network discovery, обучения, большой media validation или отдельного финального аудитора. Сохраняются неизвестные permissions/source inventories/target data/groups, sampling limits и различия claimed/actual counts. После этого автор пишет большой русский HUMAN_DRAFT, редактор сохраняет human report, compressor — английскую machine version с обязательной YAML и сохранёнными conditions/F-ID. Дополнительных итоговых файлов в корне не создавать.
