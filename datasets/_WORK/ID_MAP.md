# Сопоставление веточных ID с общими

Фиксация collector: 23.10.2026, Europe/Moscow. S/F/Q/E общие; K001–K015 сохранены. Многие веточные записи объединены; список через `/` означает несколько оснований/аспектов. Повторный пересказ одной статьи не независимый источник. Сокращённые F01/S01 внутри веточной card понимаются с префиксом её имени. E019–E033 — выполненные bounded checks; E001–E018 — предложенные программы, их статусы нельзя смешивать.
