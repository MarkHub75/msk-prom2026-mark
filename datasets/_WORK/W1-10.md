# W1-10 — условия использования конкретных данных и слоёв

Исследователь A, datasets, первая волна. Доступ 23.10.2026. Проверялись открытые первичные README/LICENSE, archive cards/API и публикации. Это карта найденных условий и неопределённостей, не юридическая гарантия. Скачивание небольшого публичного файла не доказывает разрешение на любое последующее действие.

## Что следует делать сейчас

В manifest отделять **код, аннотации, исходные фото/видео, сборку, статью и модельные веса**. Для SH17 и SHWD обнаружены существенные ограничения/расхождения, которые запрещают маркировать весь набор одним `commercial_ok`. Для CPPE-5 Apache2.0 относится к репозиторию кода, а HF прямо сохраняет unknown license данных и статья предусматривает per-image source licenses. SHEL5K v1 имеет NC3.0 на карточке. SODA/SFCHD/Pictor требуют уточнения лицензии самих данных. Mendeley smoking и заводское Önal video имеют CC BY4.0 на карточках, но первое собиралось из поиска и сохраняет вопрос upstream photo rights.

## Факты и конфликты по артефактам

**W1-10-F01 — S01/S02/S03, документ/metadata, прочитано. SH17.** README §License явно указывает **CC BY-NC-SA 4.0** и educational/research/analysis scope. Zenodo v1 API revision4 даёт **CC BY-NC 4.0**, `access_right: restricted`, `files: []`; карточка действительно сообщает restricted files. Статья v1 Introduction p2 и Conclusion говорит о research/commercial доступности. Это авторское утверждение, которое не снимает NC конкретной версии. У исходных Pexels фотографий и созданных labels могут быть разные правообладатели. Более широкая лицензия фото не отменяет NC разметки; лицензия разметки не расширяет полномочия на фото. До уточнения не назначать commercial training/deployment/redistribution положительный статус. Применимость NC к конкретному участию в хакатоне с призом также не установлена.

**W1-10-F02 — S04, текущие условия Pexels.** Terms §5 допускает download/use/copy/modify/adapt для commercial и noncommercial purposes при соблюдении запретов. Standalone distribution запрещена; простой resize/crop/filter не выводит материал из standalone. License/AUP запрещают ложное endorsement, оскорбительное представление узнаваемых людей и нарушение чужих прав. Terms не гарантирует наличие всех consents лиц/брендов. Это редакция20.10.2026, а не доказанная историческая лицензия каждого фото при сборе SH17 в2024. Дата применимых условий к каждому source image остаётся вопросом. Web прочитал документы; сохранённые shell HTML с403 являются challenge, не legal snapshot.

**W1-10-F03 — S05/S06. SHWD.** Root LICENSE — MIT, copyright2019 njvisionpower, wording относится к software/associated documentation. README признаёт часть negative heads из SCUT-HEAD и другие изображения Google/Baidu. SCUT-HEAD README §Remark: академическое сообщество, только исследовательское использование. Поэтому MIT репозитория не доказывает коммерческие права на весь SHWD. Per-image permissions для поисковых фото не найдены. Code route можно рассматривать по MIT с сохранением notice; images/labels и их перепубликация требуют отдельного основания.

**W1-10-F04 — S07. CHV.** README содержит **“open for free use”** и просьбу cite. License endpoint404 и root tree не дали стандартной лицензии. Это реальное разрешительное заявление, но его точный scope по modification/republication/commercial use не раскрыт. Оно не закрывает права upstream GDUT-HWD/SHWD, lineage которых C подтвердил первичной статьёй вW1-09. CC BY статьи Sensors не переносить автоматически на все фотографии download.

**W1-10-F05 — S08. SHEL5K.** Mendeley v1,23.04.2021, указывает **CC BY NC3.0**; parent — Kaggle andrewmvd/hard-hat-detection. Новая разметка не доказывает права на все исходные фото. CC NC3 §4 требует attribution/notices и ограничивает использование, направленное преимущественно на commercial advantage или monetary compensation. Это не ShareAlike лицензия. Применение коммерческого запрета к конкретным действиям команды не разрешено исследованием.

**W1-10-F06 — S09 и W1-04. CPPE-5.** Code repo Apache2.0; HF dataset front matter `license: unknown`. Paper §3.2 предусматривает отдельное Flickr image author/license metadata; у Google Images metadata беднее. Полный original archive с этим manifest не получен. Нельзя обосновать публичную перепубликацию всего датасета одним Apache LICENSE. Приоритет — получить source/license inventory, после чего выбирать пригодные фото и сохранять attribution. Unknown в HF не является ни разрешением, ни доказательством незаконности.

**W1-10-F07 — S10. SODA.** Статья говорит open-source и даёт VOCv1.zip. Наш запрос вернул403; внутренний LICENSE не просмотрен. Явных условий на фото/аннотации в прочитанном PDF не найдено. Download link и открытая статья не устанавливают commercial relicense. До точного условия scope данных остаётся неизвестным.

**W1-10-F08 — S11. Smoking v1.** На карточке явно **CC BY4.0**, есть citation статьи. Источник изображений — поисковые системы. CC BY позволяет share/adapt, включая commercial, с attribution/указанием изменений, в пределах прав лицензиара. Per-image upstream permissions не установлены. Вывод: заявленная лицензия архива открытая, цепочка прав на каждое фото полностью не проверена. Это ограничение проверки, а не утверждение о нарушении прав.

**W1-10-F09 — S12. Pictor-v3.** README просит citation для dataset/model/method. Root tree и license API не дали LICENSE; ответ endpoint404. Citation request не заменяет разрешение на коммерческое распространение. Crowd-sourced и web-mined изображения имеют разное происхождение. Внутренние notices Drive archive этой веткой не проверены; B отдельно исследует доступную crowd-only версию. Нужен конкретный artifact notice или авторское условие.

**W1-10-F10 — S13. CMA.** LICENSE репозитория — MIT, но README раздел CMA содержит **“only for research”** и **“do not use it for commercial purposes”**. README §License также описывает research/educational scope и обязательную attribution кода, данных, моделей и derivatives. Код и данные могут составлять разные слои; общая формулировка README создаёт дополнительную неясность для кода. Нельзя молча выбрать удобный документ. CMA оставить условным research donor; commercial dataset reuse явно не разрешён этой формулировкой.

**W1-10-F11 — S14. Önal/Dandıl.** Mendeley v1 — **CC BY4.0**; статья Data in Brief — **CC BY-NC4.0**. Это разные артефакты, а не необходимый конфликт лицензии одного видео. Авторы сообщают о company/employee permissions; мы их не аудировали. Видеоархив не получен этой веткой, notices внутри него не просмотрены. Архивная карточка является первичным основанием для условий данных; сохранять DOI/авторов и не выдавать материал2022года за собственную съёмку.

**W1-10-F12 — S15/S16. SARD и SFCHD.** SARD API `license.id: cc-by-4.0`; в двух ZIP directories отдельного LICENSE нет. Часть core filenames похожа на web source IDs; upstream manifest не получен. SFCHD exact commit7bfabb4533613e6917461dc3758dcff5f304bd03 по проверке C не содержит LICENSE/terms. Copyright статьи ACM/author не является автоматическим dataset permission. Приоритетность factory frames технически не устраняет license unknown.

**W1-10-F13 — W1-04-S06. MaskedFace-Net.** README указывает CC BY-NC-SA4.0 для сборки, а FFHQ originals имеют неоднородные BY2.0/BY-NC2.0/CC0/Public Domain Mark/US Government условия с per-image metadata. Нельзя назначить всем портретам одно commercial permission и потерять provenance после synthetic mask overlay.

**W1-10-E01 — предложено, не выполнено.** Для каждого выбранного download сохранить exact URL, version/commit, hash файла, hash найденной лицензии, scope, upstream URL/author/license, attribution text и transform history. Неизвестные значения сохранять явно. Это позволяет отдельно принять решения download/train/modify/redistribute raw or crops or labels/publish weights/deploy.

**W1-10-E02 — предложено.** Для публикации обученных весов установить точный scope условий данных. Не утверждать ни «SA обязательно распространяется на веса», ни «веса точно свободны от всех ограничений»: найденные документы не разрешают такой общий вывод для всех наборов.
