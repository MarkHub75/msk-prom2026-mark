# W1-12 — обратимый mapping классов и геометрии

Исследователь C;  дата доступа 2026-10-23,Europe/Moscow. Финальные target IDs до полного кейса не назначаются. Ниже semantic concepts, а не обещание обязательных классов. Сетевые source artifacts реально получены в C для SHEL5K/SFCHD; SH17/CPPE — явно атрибутированное чтение файлов B/A.

## Решение

Карта должна хранить source class и box unit даже тогда, когда несколько источников ведут к одному предварительному понятию. Предмет-каска, голова с каской и человек с каской — разные supervision. Нельзя обучать один detector box по их механической смеси. `unknown` означает неопределённый наблюдаемый state; `not annotated` — отсутствие supervision по этому классу. Ни то ни другое не отрицательный пример нарушения.

## Предварительная типизация соответствия

`exact` — совпадает source definition,geometry и выбранный target concept, но не автоматически протокол качества. `conditional` — нужна видимость/связь/подтип. `partial` — часть нужной семантики потеряна. `incompatible` — geometry/definition противоречат требуемому supervision. `not annotated` — source не даёт этого GT. Поле relation не заменяет полноту labels.

**W1-12-F04 — передача B с артефактом, см. W1-02-F07/W1-11:** raw Issue4 archive содержит 8102 XML / 76008 objects и теги `gloves-on/off`, `glasses-safety-on`, `glasses-vision-on`, `safety-shoes-on`, `halmet-on/off-color`. Авторский conversion удаляет on/off, цвета, safety/vision и исправляет halmet. Base17 поэтому даёт partial mapping для wearing state: helmet может включать off, glasses не равно safety goggles, shoes не равно safety boots. Raw 8102 не автоматически тот же released 8099. Нужно явно построить пересечение и учесть conversion.

**W1-12-F05 — семантика из B:** SH17 head — body part, не no_helmet; hands — не no_gloves; ear-mufs может включать headphones; face-mask связан с medical mask. Для target industrial PPE это conditional/partial map, а не доказанная сертификация. Отсутствие gloves label в кадре с перчаткой не является negative по базовой карте.

## CPPE-5: IDs и неоднородный Mask

**W1-12-F06 — чтение результата A, S06:** original README IDs: 1 Coverall, 2 Face_Shield, 3 Gloves, 4 Goggles, 5 Mask. HF category IDs: 0 Coverall, 1 Face_Shield, 2 Gloves, 3 Goggles, 4 Mask. Это разные representations. HF bbox — COCO xywh в пикселях. Source image_id1012 с filter halfmask размечен category4 Mask. Поэтому нельзя ни объявить весь Mask industrial respirator, ни утверждать, что респираторов на изображениях нет. Mapping exact для broad source Mask; conditional после ручной классификации подтипа к target respirator. State correct/removed/unknown не размечен.

Goggles — донор объекта eye protection, но не безусловное равенство SH17 glasses; Face_Shield — щиток, а не респиратор. Broad merge в face_protection возможен только при осознанно переопределённой целевой задаче с сохранением original ID и definition.

## Обратимая запись manifest

Предлагаемая schema,не original annotations:

```yaml
source_family: SHEL5K
source_revision: '10.17632/9rcv8mm682.1'
source_file: hard_hat_workers0.png
source_annotation: hard_hat_workers0.xml
source_class_id: null
source_class_name: head_with_helmet
source_geometry: bbox_xyxy_pixels
source_bbox: [360, 118, 406, 175]
coordinate_convention: source_preserved_inclusive_exclusive_unconfirmed
semantic_unit: head_region
concept: helmet_presence
state: present
mapping_relation: conditional
mapping_version: provisional-datasets-w1
person_association: null
visibility: unreviewed
coverage: source_claimed_complete_not_locally_validated
target_class_id: null
transform_history: []
```

Не удалять source box после resize. VOC inclusive/exclusive convention нельзя подменять по имени формата: сохранить происхождение, подтвердить round-trip на конкретной реализации конвертера. Для COCO явно хранить xywh; для YOLO — normalization image width/height и letterbox padding. `source_class_id: null` отличается от ID0.
