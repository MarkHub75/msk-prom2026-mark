## SH17: реально непересекающиеся имена, неизвестные фотосессии

**W1-14-F01 — авторский protocol S01.**80% train/20% test; separate lists. В readme говорится train/test, а реально полученный Kaggle файл называется val. Github YAML test пустой, val placeholder. Не создавать несуществующий третий независимый split из одного и того же1620-file списка.

**W1-14-F02 — наше наблюдение S02.**6479train/1620val unique basenames,intersection0,union8099. URL manifest8099 uniqueURLs. Один basename mismatch: `carrying-on-head-indian-farm-worker-158011.jpeg` в URL и `carrying-head-indian-farm-worker-158011.jpeg` в split/rawXML. Это конкретная подготовительная проблема, не evidence data leakage. Материал SH17_split_audit.json. Изображения не скачивались для сравнения pixel hash.

**W1-14-F03 — документ S01, unknown.** Authors say duplicates removed before final collection. Нет метода/distance threshold/cluster manifest на прочитанных страницах. Metadata TableVI обещает PexelsID/photographer ID/URL/description/dimensions; это потенциальный grouping aid, но полный metadata artifact не получен. Photographer ID — не camera/session ID. Один фотограф может иметь независимые съёмки, одна фотосессия может иметь много близких снимков. Не объявлять random image split независимым от сессии.

**W1-14-F04 — наше наблюдение raw derivative, W1-11.**8102 rawXML против8099 URL,3 extras. Base split нельзя применить ко всему rawZIP без intersection manifest. Raw on/off/crop/augmented derivative наследует original group и split. Новые labels не создают независимые изображения. TableII/VIII counts конфликтуют, поэтому derivative сравнивать только после фиксирования составов.

## Доказанная повторность generic benchmarks

**W1-14-F05 — официальный документ S03.** MOT17 повторяет MOT16 sequences с обновлённым GT. Три варианта DPM/FRCNN/SDP — разные public detections на одной базовой последовательности.21train entries=7base sequences×3,21test likewise. Это установленная структура, не предположение по похожим именам.

**W1-14-F06 — наш hash audit S03.** Все21 train GT files из реально скачанного MOT17Labels.zip сгруппированы по SHA256 bytes:7hash groups,каждый ровно3detector variants. Пример MOT17-02-DPM/FRCNN/SDP имеют одинаковый GT. Это фактически найденные **дубли annotation content**, не самостоятельный pixel hash audit image ZIP. Хеши/пути сохранены MOT17_GT_hash_groups.json. Не суммировать три варианта как triple unique scenes и не разносить их между train/eval.

**W1-14-F07 — официальный документ S04.** COCO2017 train/val перестроен из тех же2014images; новые year tasks не дают новые data.2018 detection/keypoint без изменений,2020всеchallenge data unchanged. Train2014 иval2017 нельзя без image-ID comparison считать независимыми. Split year, annotation task year и source image год — разные поля.

CrowdHuman имеет official train15000/val4370/test5000 images, но не получены photographer/session grouping и проверенные overlap manifests с COCO/SH17. Только разное имя датасета не устанавливает независимость. PPE completeness на этих person datasets вообще отсутствует.

## PPE families: установленные родители и риск общих видео

**W1-14-F08 — первичные источники, полученные C, S07 (W1-03-F05–13/W1-09).** CHV отбирает исходные изображения SHWD иGDUT-HWD. SHEL5K переаннотирует5000images KaggleSHD. Это реальные lineage relations, поэтому parent/child не независимые holdouts. Exact состав конкретной training mixture всё равно сверять по файлам; не заявлять конкретное число cross-over без сравнения. SHEL5K authors random4000/1000, scene groups не установлены; formal split lists в просмотренном Mendeley folder C не нашёл.

**W1-14-F09 — первичный SFCHD protocol/artifact C, S07/W1-03-F14–18.** Две chemical plants,около40scenes; frame sampling каждые10frames при наличии людей, неделя записи. Это основание ожидать коррелированные соседние кадры, а не доказанный split leakage. Current file train9897/val2475 (sum12372),COCOall images12373,missingTXT и tinytest6paths/emptytestJSON описаны C. Наличие IP-подобных prefixes в filenames может помочь source grouping, но camera/session interpretation не установлена. До scene-group audit SFCHD полезен для адаптации CCTV, не автоматически независимый temporal holdout.

**W1-14-F10 — Pictor S05.** Crowd/web components774/698 заявлены отдельно; retrieved Drive показывает папкиImages/Labels/Models,actual split manifests B не получены. Сравнивать Approach1/2/crops как независимые datasets нельзя: это разные annotations/tasks на тех же исходных сценах. Frame/time/session IDs неизвестны.

**W1-14-F11 — Harness S06.** Статья указывает transformed helmet data +surveillance+web; split16:4:5. Tree3300XML/3300JPEG не содержит manifests. Filenames DangerousNNNN/SafetyHarnessNNNN — class-related sequence naming, не доказанные original video IDs. Разрезать consecutive video frames на случайные части рискованно. Связь с Wang helmet dataset — primary stated parent, но точная связь сCHV/SHWD version требует image comparison. ДваsampleXML не решают независимость.

## План exact/near/group audit — предложено, не исполнено на изображениях

W1-14-E01. Для каждого точного artifact создать immutable manifest: dataset/ref/version/retrieved_at/archive_hash; original_path/source_image_id/source_URL; image_bytes_hash/decoded_pixel_hash;dimensions; annotation_hash;official_split;parent/crop/augmentation_chain;source_group/group_evidence;usage_role. Не выдумывать missing groupID: null и reason.

W1-14-E02. Exact duplicate stage: сравнить raw file SHA256 и canonical decoded pixel SHA256 (для re-encoding/metadata differences); группы duplicate originals наследуются всеми crops/augmentations. Это различает byte duplicate и pixel duplicate. Логировать до/после canonicalization,orientation,colour conversion. На найденных conflicts не просто удалять строки: quarantine всей connected component до решения.

W1-14-E03. Near duplicate stage: perceptual hash/embedding retrieval кандидатов внутри и между parent families, затем ручная проверка. Порог определяется примерами, не выдаётся за универсальную гарантию. Отделять соседние video frames, burst photos,crops,resize,flip и похожие независимые сцены. Сохранить image pairs, score, visual decision,why shared/not shared. Не утверждать отсутствие пересечения только потому, что pHash threshold не нашёл пар.

W1-14-E04. Group audit: camera/site/session/video/photographer metadata +filename patterns +visual clustering. Human review uncertain groups. Держать connected source groups в одном split; минимум все detector variants/crops одной базы вместе. При нехватке source metadata считать такой holdout ограниченным и выделить независимый targetcamera материал позже. ДляSFCHD восстановить original clip/camera/time по авторам/manifest вместо произвольного interpretationIP.

W1-14-E05. Развести роли: training/adaptation; development calibration/threshold tuning; locked independent holdout. INT8 representative samples/threshold selection использоватьdevelopment, не finalholdout. Если организатор testединственный, не использовать его для настройки. Official author test сохранить для сравнительного reproduction, отдельно от нового grouped target test. Повторные решения по результатам holdout делают его development; это отражать вmanifest.

## Точный остаток неизвестного

Ни один image-level duplicate audit здесь не выполнен. Есть доказанные lineage и repeatedannotation content, filename disjoint SH17, но нет доказательства независимости фотосессий SH17/Pictor или камер SFCHD. Не получены complete upstream source manifests, exact SH17 released label mapping, hash совпадения CHV↔SHWD/SHD↔SHEL5K и original temporal groupsharness. Для finalcase нужны camera/site/sessionIDs и правило запрета tuning на организаторском test. → evaluation основная передача; → training_strategy groupedmixture; → model_stack derivatives сохраняют originalsplit; → hackathon_strategy не обещать crossdataset independent accuracy без проверки.
