## Решение для команды

SHWD нельзя загружать как generic person detection: авторский loader называет классы `hat`, `person`, но README определяет вторую категорию как головы без каски. SHEL5K полезнее для явного разделения предмета, головы и человека, однако это переаннотация SHD и имеет ограничение NC на карточке Mendeley. CHV — донор person/vest/цвета каски, частично происходит из SHWD. SFCHD — наиболее содержательная найденная здесь промышленная CCTV-ветка: отдельные blurred-классы позволяют сохранять неопределённость. Для неё реально получены annotations и обнаружена конкретная непарность файлов.

### CHV — Color Helmet and Vest

## Следующие проверки

1. SHWD: получить 20–50 XML/paired images и подтвердить head geometry, обычные головные уборы и переносимые каски; не нормализовать `person` до этого.
2. SHEL5K: пересчитать все XML после проверки допустимой цели использования; сохранить parent SHA/filename, не смешивать SHD test с SHEL5K train. Три примера доказывают различие геометрии, но не качество набора.
3. SFCHD: получить images по авторскому download; проверить missing TXT/пустые labels, реконструировать split по basename и группировать камеры/серии. При объединении COCO/YOLO определить предпочтительную исходную версию и сохранить расхождения.
4. Для всех наборов: carried helmet, ordinary hat, correct fastening и occlusion state остаются неизвестными без инструкции и выборочного разбора. Отсутствие каски label не является целевым no_helmet.

Передача → model_stack: точные maps и geometry; → evaluation: CHV←SHWD, SHEL5K←SHD и кадры SFCHD требуют group split; → training_strategy: blurred/unknown сохранять, partial labels проверять до объединения.
