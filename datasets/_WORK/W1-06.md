Исследователь C. Дата доступа 2026-10-23 Europe/Moscow. Полного кейса нет; курение рядом с горючими — пример, а не определённый organizers event protocol. Реально выполнены сетевое получение metadata/архива, чтение первоисточников и подсчёт структуры. Модели не обучались.

## Вывод для выбора данных

Smoker Detection v1 можно получить целиком без регистрации; это маленький донор image/crop classification с полезными похожими жестами. Он не даёт cigarette boxes и не является оценкой промышленных событий. Для temporal donor доступен HMDB51 `smoke`, но кино/web clips не заменяют длинное CCTV. Новая сильная зацепка PhysicalAI содержит smoking/vaping chunks и timestamps, однако synthetic generation, free-text labels и train-only резко ограничивают её роль. SED/SED-FL не принимать за видеонабор только потому, что при сборе использовали камеру: выдаются wearable signals.

- **W1-06-F02 — реально получено:** Mendeley file `Smoker Detection.rar`, file-id `c386d8e9-2b49-4ade-ae3b-fb2f63815eaf`,65,575,997 bytes. - **W1-06-F03 — наш manifest count:** RAR содержит 1120 `.jpg` и 4directory entries. JPG распределены 716Training/224Testing/180Validation. Это подтверждает размер splits статьи. ## HMDB51 — temporal class donor

**W1-06-S02:** [официальная страница Serre Lab](https://serre.lab.brown.edu/hmdb51.html), Downloads/Action classes/Meta-labels. Авторы Kuehne,Jhuang,Garrote,Serre,Poggio, ICCV2011. На открытой current странице 6849short clips/51classes; official unstabilized и отдельный stabilized вариант,3split lists, linked CC BY4.0. Страница открыта; сами 2GB видео не получены.

**W1-06-F06 — документ:** классы `smoke`, `eat`, `drink`, `chew`, `talk` дают action clips и plausible confusers. Доступны meta-labels viewpoint/quality/light/focal-length. Это фильм/web video, не industrial CCTV. Нельзя трактовать clip class как точное время каждого puff, cigarette visibility, smoking near flammable material или event boundary. Загрузка `smoke` и выбранных confusers имеет смысл для проверки temporal feature pipeline после проверки точного release/license; не для финальных false alarms per camera-hour.

**W1-06-F07 — card:** labels1612parents/3796chunks; derived `Smoking / vaping` family282chunks, но это reporting family поверх free-text `anomaly_type`, а не готовая closed ontology сигарет. `start_time_sec`,`end_time_sec`,`fps` и chunk paths заданы. Generated media Veo3/Cosmos3 Super, labels hybrid с частично model-generated captions. Train-only. Содержит hard negatives; конкретное покрытие eating/phone/inhaler против курения требует отдельного разбора records, не предположено.

**W1-06-F08 — наше чтение JSON:** labels.json8,656,320bytes реально получен. Регулярное выражение `smok|vap` по parent `anomaly_type` выбирает 187parents:96NV-VAD-v1,87NV-VAD-v1.1,4VAD-R1. Это поисковое наблюдение, не пересчёт 282 семейных chunks и не гарантия истинного smoking class. Примеры сохранены `SMOKING_RECORD_SAMPLE.json`. Нельзя включать fire smoke по одному substring: надо использовать deterministic family mapping и проверить семантику.

**W1-06-F09 — доступ/права:** redistributable media только NVIDIA-generated; CHAD/VAD-R1 rows — source pointers без видео. Repo tree показывает videos.zip7,954,992,209bytes и chunks.zip3,853,242,520bytes. NVIDIA Dataset License и дополнительные Google conditions для Veo; license PDF полностью здесь не анализировался, commercial permission не утверждаю. Роль — candidate synthetic augment/negative/event plumbing, после условий и ручной проверки. Не real industrial holdout.

## Предложенные проверки

**W1-06-E01:** для Smoker RAR декодировать все 1120JPG, сверить размер/пары filename-label, найти exact/near duplicates и общий person/session/web origin. Выборочно audit Smoking/NotSmoking и особенно phone/drink/inhaler. Сохранить перечень размытых/малых cigarette cases. Успех подтверждает полезность crop donor, но не видео-events.

**W1-06-E02:** после полного кейса собрать небольшой целевой непрерывный validation: smoking onset/offset, person ID, cigarette visible/unknown, hand-to-face, phone/drink/eat, unrelated smoke/fire, zone+flammable context. Назначить `unknown` при недостатке пикселей. Разделить камеры/людей/сессии. Измерение camera-hour false alarms и event latency возможно только с такими материалами; текущий веб-набор этого не предоставляет.

**W1-06-E03:** для PhysicalAI сначала проверить smoking-family records и лицензию; затем выборочно скачать только связанные media и сверить manifests, temporal bounds и synthetic artifacts. Не суммировать parent/chunk counts, не переносить production precision с synthetic test.

Передача → violation_methods: cigarette evidence, image smoker и temporal event разные единицы; → training_strategy: hard confusers реальны, но category-specific labels не выданы; → evaluation: нужна независимая целевая непрерывная камера; → operator_product: состояние visible/unknown должно переживать event aggregation.
