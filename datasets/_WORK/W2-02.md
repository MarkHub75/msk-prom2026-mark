В sample отсутствует отдельный vest on only отбор, но vest on виден в 8488036 и 13376117. Результат не является случайной репрезентативной выборкой.

## Практическое решение

**W2-02-F09**: использовать SH17 как условный донор объектов с raw state в отдельном поле и 17-class released map из W1-02. Не обучать absence detector автоматически на всех off. Для конкретного wearing adaptation дополнительно размечать `person_id`, `ppe_object_id`, `association_evidence`, `observed_state` (worn/unworn/adjusting/unknown), видимость нужной части тела и annotation completeness; нарушение правила и event остаются отдельными слоями. Person box может происходить от demographic raw labels: такую информацию не переносить в таксономию продукта и не выдавать за явную разметку отсутствия СИЗ у человека.

**W2-02-E01 (выполнено)**: выбор 13 пар по `GET_SAMPLE.py`, decode через PIL, declared versus decoded size, overlays и ручное чтение CONTACT0–3. Сохранённые originals не менялись. Метрики:13 image payloads,13 XML,12 equal declared sizes,1 mismatch; ошибочность классов количественно не измерялась. **E02 (выполнено в W2-01)**: получены те же 13 released YOLO basenames; 228 mapped raw boxes совпали с released при tolerance 1e-6. Это не подтверждает semantic correctness. Ручное исправление остаётся предложением только для производной копии после выбора целевой задачи.

Q-W2-02-01: является ли `off` по официальной инструкции исключительно ненадетым предметом или допускает и body region absence? Нужен protocol/ответ автора, sample устанавливает только наличие случая отдельного предмета. Q02: какие raw classes/objects удалены при release cleanup? Адресная W2-01. Q03 закрыт для выбранного sample: W2-01 получил exact released JPEG 13376117 с dimensions 8192×5461. Текущий Pexels JPEG не использовался для исправления source boxes. Лицензии raw labels/фото см.W2-12; доступность URL не является разрешением на публичное распространение.

**W2-02-F10 — разрешение coordinate discrepancy.** W2-01-S02/F05 получил через официальный Kaggle single-file endpoint ZIP с одним JPEG 13376117; после распаковки реальный размер 8192×5461 совпал с raw/released VOC. В `MATERIALS/W2-01/RELEASE_COORDINATE_OVERLAY.jpg` выполнено прямое наложение на этот annotation frame, визуально bbox согласуются с рабочими/предметами. Прежний CONTACT0 с текущим Pexels image сохраняется только как иллюстрация ошибочного frame pairing, а не как доказательство неверных author coordinates.
