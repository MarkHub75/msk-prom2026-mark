## Pictor-v3: жилет и person-state геометрия

**W1-05-F01 — авторский README S01, прочитан.** Pictor-v3:774 crowd-sourced images/2496 workers и698 web-mined images/2230 workers. Это авторские числа, не локальный file count. В SH17 related work встречается784 public images — вторичное описание не исправляет774 первичного README. Не объявлять1472 фото реально скачанными или доступными одним пакетом.

**W1-05-F02 — документ S01.** Approach1 детектирует `worker`, `hat`, `vest` как отдельные объекты, после чего ML classifier определяет W/WH/WV/WHV. Approach2 локализует **worker** и относит его к W(no hat/vest), WH(only hat), WV(only vest), WHV(both). Approach3 классифицирует crops workers. Эти разные единицы supervision нельзя склеивать как один object label map. Цифровые ID в реальных annotations не проверены. В README annotation example остался TODO, формальных правил occlusion/min-size/incorrect wearing не найдено.

**W1-05-F03 — наблюдение S02.** Drive HTML выдаёт Images,Labels,Models (изменение папок10.09.2024); это живой указатель, не успешное получение файлов. В repo tree нет LICENSE. Citation request не является полной лицензией изображений/annotations/code. Для данных/перераспространения/продукта условия остаются неизвестными. Роль vest donor — условная после разрешения и sample audit. Нет gloves/boots/harness/coverall в описанной трёхклассовой object схеме.

## Harness: найдена цепочка от статьи к реальным VOC annotations

**W1-05-F07 — первичная статья S05, section4.1.2.** Авторы описывают3300 images:2000 clothes и1300 safety harness; источники — преобразованный helmet dataset Wang et al., surveillance recordings, web crawl. LabelImg вручную, person whole body, safety harness/clothes chest region. Split16:4:5. Reflective vests добавлялись как сложные альтернативы harness. Это useful class donor и основание отдельно проверять связь с helmet family; не доказательство фактических дублей с конкретной версией SHWD/CHV.

**W1-05-F08 — наше наблюдение S06.** `git ls-tree -r --name-only` pinned commit дал6600 paths:3300XML,3299.jpg+1.JPG. Это tree entry counts, не число декодированных/парных images. В tree только Annotations/JPEGImages: split manifests/LICENSE не найдены. Получены2 XML через raw pinned URLs, весь image dataset не скачивался. Список `harness_tree.txt`. Partial git metadata около255KB; попытка long-tree с lazy blob-size lookup остановлена, чтобы не получать все blobs.

**W1-05-F09 — XML наблюдения S06.** `Dangerous0001.xml`,400×486: clothes bbox[109,63,266,166], person[77,11,342,352]. `SafetyHarness0001.xml`,1920×1080: safety-harness bbox[608,183,908,613], person[403,1,950,1078], person truncated1. Геометрия действительно chest-inside-person; numeric category IDs не присутствуют, текстовые labels. Relation ID отсутствует. Видимость/occlusion могут мешать association. Два samples не подтверждают полноту всего набора и не доказывают пристёгнутый anchor/hook. Название Dangerous — filename, не interval event ground truth.

**W1-05-F10 — ограничение/следующий шаг.** В статье data/program openly available направляет только на GitHub account, оттуда найден Dataset repository; code не найден в tree. Разрешающие условия dataset/code/image публикации не найдены. Доступ без регистрации есть для двух XML; permissive license не заявлять. Для harness задачи этот источник полезнее непроверенного Roboflow export: определена chest geometry и parent mixture, но rights/independent splits требуют работы.

W1-05-E01: samples Pictor Approach1/2 сверить с image и numeric IDs, отдельно cloth overlap/occlusion/unknown; выяснить scope доступной crowd/web частей и terms. До этого не объединять vest boxes и worker-state boxes.

W1-05-E02: получить малый Construction-PPE sample, определить все none/no_* bbox definitions, missing-label completeness и upstream source. Проверить worn-gear формулировку на реальных examples. Ничего этого пока не выполнено.

W1-05-E03: harness взять стратифицированно Dangerous/SafetyHarness, мелкие/перекрытые/reflective-vest примеры; проверить person→chest пары, filename case и исходные video groups. Не обучать до решения rights, не использовать random frame split как независимую камеру.

Существенно неизвестны: корректное ношение gloves/boots/harness; anchor/hook supervision; Pictor actual annotations/terms; Construction-PPE geometry/provenance; exact harness source scenes/split/rights. → training_strategy donors; → violation_methods association и невозможность вывести secured harness; → evaluation group/parent leakage; → model_stack сохранить разные bbox units.
