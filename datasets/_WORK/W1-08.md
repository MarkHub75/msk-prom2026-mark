## COCO 2017: person/pose donor, не PPE ground truth

**W1-08-F01 — первичная документация S01, прочитана.** Official download показывает2017 train118K/18GB, val5K/1GB, test41K/6GB и train/val annotations241MB. Это округлённые размеры сайта, не наши file counts. В2017 переиспользованы те же изображения2014 train/val с новым118K/5K split: разные года не означают независимые наборы. Выпуск2020 не добавляет новых detection/keypoint data.

**W1-08-F02 — format-data.htm, документ.** Object JSON связывает `image_id`, `category_id`, `[x,y,width,height]`, `segmentation`, `iscrowd`, `area`. Координаты от левого верхнего угла,0-indexed. Image metadata содержит id,width,height,file_name,license,flickr_url,coco_url,date_captured. Не выдумывать camera/session IDs: их нет в показанной схеме. Actual category-ID list не получен из annotations; точные IDs при конверсии читать из `categories`, не из списка80 классов сторонней библиотеки.

**W1-08-F03 — документ S01.** Keypoints имеют `(x,y,v)`, v0 not labeled, v1 labeled not visible, v2 visible; `num_keypoints=0` встречается у small objects/crowds. Pose аннотирован для большинства medium/large non-crowd people, не для всех людей. Поэтому отсутствие точки или скелета не равно отсутствию части тела. Ключевые точки могут ограничить ROI головы/кистей/стоп, но не удостоверяют надетые перчатки/каску/респиратор. Сайт2020 указывает >200K images/250K persons with keypoints across train/val/test, публичные train/val >150K people/1.7M labeled keypoints: авторский объём, не локальный подсчёт.

**W1-08-F04 — terms S01.** Аннотации/website CC BY4.0; изображения не принадлежат consortium, условия Flickr и права конкретного image применяются отдельно. Software имеет отдельный текст redistribution. Нельзя присвоить всем фото blanket CC BY4.0. Не скачивались изображения/полные annotations; ветка ограничена schema/roles.

## CrowdHuman: связанная геометрия full/visible/head

**W1-08-F05 — заявление первичных авторов Shao et al.,2018, S02.** Train15000/val4370/test5000 images,470K persons в train+val,23 persons/image. Это сильная зацепка для occlusion, crowd и person↔head ROI. Домены web crowd images; industrial CCTV сходство не проверено. Аннотированный PPE state отсутствует в протоколе.

**W1-08-F06 — официальный формат S02.** ODGT — JSON на строку: image `ID`, массив `gtboxes`; каждый box содержит `tag`, `vbox`, `fbox`, `hbox`, optional `extra` и `head_attr`. `vbox/fbox/hbox` — visible/full/head bbox, `[x,y,w,h]`. Extra/head_attr могут содержать ignore,occ; head_attr также unsure. Важный literal: `tag="mask"` здесь означает crowd/reflection/person-like ignore region, **не медицинскую маску**. Сохранять ignore/unsure, не преобразовывать в person/PPE positive.

**W1-08-F07 — terms S02.** Использование images только non-commercial research/education; распространение images запрещено; disclaimer о правах. Предоставлены Drive/Baidu download links и annotations train/val, но файлы ODGT/изображений нами не скачаны, их counts не пересчитывались. Точный revision dataset не опубликован на прочитанной странице. Ссылки доступны как документация, не доказательство успешного image download.

## MOT17: проверка трека и времени, не PPE events

**W1-08-F08 — текущая первичная страница S03.** MOTChallenge online web application и evaluation закрыты; доступен архив результатов (state16.04.2026) и download. Это меняет практику: для hackathon локальная оценка треков, не обещание новой submission. Conditions CC BY-NC-SA3.0 плюс возможные third-party source conditions.

**W1-08-F09 — документ S03 + фактическое чтение S04.** Official page21 train/21 test sequence entries, но каждая базовая последовательность повторена с DPM/FRCNN/SDP. Это14 base sequences total, не42 независимых видео. Все MOT16 sequences используются повторно с новым GT. Изображения не скачаны. Labels ZIP реально содержит train/test seqinfo, train GT и public detections. Sample seqinfo `MOT17-01-DPM`: frameRate30,seqLength450,width1920,height1080. Sample GT имеет9 числовых столбцов, стабильный track ID по нескольким frames; интерпретация class7 в sample здесь не предполагается без instruction table. Отдельный instructions URL вернул410; сохранять category filtering перед оценкой.

**W1-08-F10 — вывод из S03/S04.** Роль: regression test трекера, переключений ID/occlusion recovery, счётчика кадров/времени и подавления повторных тревог на искусственно заданных правилах. Городские улицы/торговые центры, есть moving cameras; нельзя измерить industrial PPE violation quality. Polygons/danger policy/PPE intervals не содержатся. Calibration по person flow возможна только отдельным development split; не заменяет target holdout.

## Маршрут использования и отсутствие ложных негативов

W1-08-F11 — вывод. Для PPE detection loss не считать все unlabelled PPE pixels background. Generic donor даёт person supervision, отдельный pose task либо отобранные crops. Для negative PPE image/class требуется ручная проверка видимости нужной body region и фактического отсутствия target equipment. `not annotated`, `occluded`, `out of scope`, `verified absent` хранить отдельно. COCO `iscrowd`, CrowdHuman ignore и MOT distractor/class filtering должны пережить conversion.

W1-08-E01 (предложено): небольшой стратифицированный audit person/head: crowd/noncrowd, scale, occlusion; проверить F/V/H bbox соответствие, class filtering и сохранение ignore. Сохранить выборку IDs и failure types. Успех не подтверждает PPE quality.

W1-08-E02 (предложено): для MOT выбрать development sequences по base ID, все3 detector variants держать в одной группе; посчитать ID switches/track fragmentation и latency pipeline на известном FPS, отдельно от PPE-event correctness. Сам tracking test не выполнен.

Открыто: exact COCO category IDs по выбранному artifact, CrowdHuman actual file integrity и фотографические группы, MOT instructions/class mapping текущего архива, target camera domain и разрешённость дальнейшего использования в предполагаемом продукте. → training_strategy person-only/partial labels; → violation_methods геометрия/track; → evaluation target holdout отдельно; → video_architecture FPS/seqinfo fixtures.
