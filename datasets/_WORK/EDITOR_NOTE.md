## Что особенно сохранить сжимателю

1. SH17: **13 released YOLO-файлов / 228 annotation boxes** сравнивались с mapped raw. **13 raw XML/current Pexels** относятся к отдельному визуальному просмотру. Только для **13376117** получен exact released JPEG; это **не 13 полных release media/label pairs**. Разрешённое расхождение coordinate frame нельзя возвращать в статус массовой ошибки исходной разметки.
2. SFCHD: полный COCO 12,373/50,559 и рабочее media intersection 12,372/50,552 различаются. Missing JPEG не восстанавливается старым TXT. Два val-протокола различны, tiny test пересекается с TXT val. Префиксы и runs — inferred proxies. Порог small `<0.1%`, large `>0.2%`, а не SPIE 0.12%; 518 малых численных выходов отделены от 12 существенных.
3. SHEL5K: 75,578 = 75,570 шести классов + 8 unresolved `person`; blanket no_helmet mapping опровергнут. CPPE: Apache 2.0 автора распространяется на code **и annotations**, права фотографий отдельно; PNG 762 остаётся coordinate/version quarantine. Construction `no_*` локализованы на частях тела, `none` не переименован в no_vest. PhysicalAI family — 282 chunks/157 parents; 187 относится к другому substring scope.
4. E001–E018 — предложенные программы, E019–E033 — выполненные bounded checks с узким охватом. Ни полнота выбранных media, ни модельное качество, ни перенос на CCTV, ни LinQ performance не установлены.

## Существенные ограничения

Редактура использовала только входные промпты, авторский черновик и замороженную доказательную базу. Новых сетевых запросов, исследований, агентов, писем владельцам или вопросов пользователю не было. Авторские неизвестные и условные рекомендации сохранены. Полного кейса, organizer media, финальной таксономии и входного контракта LinQ в базе по-прежнему нет; следующая практическая работа начинается с их приёма и фиксации целевого holdout.

Markdown проверен структурно, включая ссылки, якоря, таблицы и код. Установленного стандартного Markdown-рендерера в доступных Python/CLI/Node-инструментах не найдено; пиксельная визуальная проверка рендера не заявляется. Это ограничение редакторской проверки, а не поручение запускать отдельного аудитора. Работа следующей согласованной роли — machine compressor без новой сети.
