Проект: SafeWatch (`msk-prom2026-mark`), видеоконтроль промышленной безопасности на LinQ TPU. Источник истины: `tech.md`, читай перед каждой задачей и подчиняйся дословно. Зачем: `docs/brief.md`. Факты о LinQ: `docs/linq/LINQ_CONTRACT.md`.

## Контракты
- Схему, типы, фасад, маршруты, WS-сообщения, ключи конфига не выдумывай: всё из разделов 5–6 `tech.md` и строк `GAP` в `## open`.
- `tech.md` не редактируй. Нет контракта: `CONTRACT GAP` по разделу 14, работа не останавливается (простейшая совместимая форма, строка `GAP` в `## open`).
- `contract/openapi.json` — контракт фронта Егора: только добавления, удаление и переименование — через владельца.

## Работа
- Владелец не у терминала: вопросов не задавай, допущение называй и записывай.
- Один шаг за сессию: первый незакрытый в очереди раздела 16. Слайс закрыт по DoD раздела 13; ревью `R<K>` по разделу 17.
- Режим ночи (раздел 10.1): всё к 10:00 МСК. Тесты облегчены, браузер не открывать, CI проверять только на ревью, фронт минимальный (8.14): днём его заменит фронт Егора.
- `main` всегда зелёный; невыполненный критерий: строка `долг: ...` в `## open`.
- Цикл (раздел 11): ветка `slice-N-<name>` → коммиты по ходу → `uv run poe gate` → push → PR → `gh pr merge --squash --delete-branch` → удалить ветку. CI не ждать.
- Ни одна команда не ждёт молча дольше 4 минут: `timeout 230 bash -c 'until <проверка>; do sleep 5; done'` или `run_in_background`. `sleep N; команда` Claude Code блокирует.
- `## night` ведёт только оркестратор `/night-shift`. Заметка для ревью: строка `R<K>: <что>` в `## open`.
- Лимит живых прогонов: один прогон LinQ на шаг и только в S2 и R5 (ролик до 60 с, одна задача baseline на TPU, `--inflight 4`); туннель недоступен — работа на `SAFEWATCH_FAKE=1` и строка `долг`.
- LinQ (раздел 3.1): аккаунт Jupyter и брокер общие с Матвеем; наше только в `~/work/baseline/` с префиксом `baseline_`; программы `mosprom_*` не перезаписывать; чужие программы, очереди, папки и ветку `matvey_cv` не трогать.
- Реальные настройки владельца (Claude Code, профиль, ОС) не трогай: такие команды только с путём на временный файл.

## Платформа (Windows, Git Bash)
- Файлы и правки длиннее 30 строк только через Write/Edit. Heredoc в Bash до 30 строк, без `\\` (инструмент превращает `\\` в `\`).
- Python-скрипт правки кладётся файлом и запускается по пути.
- Ожидание: `timeout 230 bash -c 'until <проверка>; do sleep 5; done'` или `run_in_background`. Цепочка `sleep N; cmd` заблокирована.
- Пути для Windows-программ из Git Bash передавать целиком или с `MSYS_NO_PATHCONV=1`.
- `.env` в шелле не читать (ключи проверяет `uv run safewatch doctor`). Не использовать `git stash`. `ruff check --fix` только по путям.
- PowerShell 5.1: файлы не писать через `Set-Content`/`Out-File` (ANSI или BOM). Ненулевой код после `-ErrorAction SilentlyContinue` не считать ошибкой.
- Порт сервера освобождает `uv run --no-sync safewatch stop`, а не ручной `Get-NetTCPConnection` + `taskkill`.
- Временный локальный конфиг живой проверки удаляется в той же сессии. Тесты не читают локальный конфиг владельца.
