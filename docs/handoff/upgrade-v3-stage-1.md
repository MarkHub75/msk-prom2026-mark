Фактически в контейнере: `/app/data/app`, `/app/frontend/dist`, `/app/data/demo/argus-real-v2`, backend `linq`, fake `false`, target 12, min 5, extra пуст. Дополнительных классов в этом кэше нет; наличие файлов в read-only `models/` не означает их выполнение.

Загрузка YAML: `default.yaml → user.example.yaml → user.yaml`, рекурсивное слияние, неизвестные ключи запрещены. Compose монтирует `./config/user.yaml` в `/app/config/user.yaml` read-only с `create_host_path: false`; пользовательский файл исключён из build context и не запекается. ### Формулы и железо

Пусть N — камеры, p — доля активности, `A95 = percentile95(Bin(N,p))`; `fps_active = pipeline.target_analysis_fps = 12`, `surge_fps` не ниже `pipeline.min_analysis_fps = 5`, `models_cam` — число нужных моделей. Для неоднородных камер обосновать агрегацию, не подставлять молча одинаковый набор.

```text
active = fps_active / det_stride × models_cam
idle = 1 / idle_check_s (= 0,25)
peak = A95 × active + (N − A95) × idle
surge = N × min(fps_active, surge_fps) / det_stride × models_cam
required = max(peak, surge)
chips = ceil(required / (vendor_fps × derate))
cpu_cores = required × cpu_ms_per_frame / 1000 + N × decode_cores_per_camera
servers = max(ceil(boards / slots_per_server), ceil(cpu_cores / cores_per_server))
electricity_year = watts / 1000 × 8760 × tariff_rub_kwh
```

На всплеске всем камерам гарантирован минимум, а камерам с открытым событием — полная частота; это дополнительное ограничение расчёта мощности нужно выразить явно. Подобрать **самую дешёвую допустимую комбинацию плат**, не просто разделить chips: HP — 1 чип, до 35 Вт по мануалу, цена 500 000 ₽ только допущение; HPD/HPQ без цены до данных. Слоты/CPU оба ограничивают серверы. `cpu_ms_per_frame ≤77` — верхняя оценка из 19,5 кадр/с при квоте 1,5 CPU с хвостом/декодом; сверить `LINQ_CONTRACT.md`, не выдать за отдельный точный CPU-бенчмарк.

Главный график — ступеньки, каждая меняет одно допущение и показывает чипы и рубли: (1) «как сейчас» S24, (2) выделенная ёмкость, (3) модели по камерам, (4) пул пика + idle + surge floor, (5) трекер, только если включён. - Метрики площадки RTT/throughput/inflight с подписью «упирается в очередь площадки». `inference_time` p50/p90 только если есть ответы/логи, смысл организаторами не подтверждён; нет поля — строки нет. События/камеру/день — существующий измеряемый вход с честным определением.
- Пресеты: «Мастерская» — 5 станков, 100 м², 5 камер; «Цех» — 10 000 м², камеры через явное допущение на 1000 м²; «Завод» — несколько цехов, около 200 камер. Работники/смены/рабочие дни — редактируемые подписанные допущения.
- Кривая масштаба: ₽/камеру/месяц при 5, 10, 25, 50, 100, 200, 500 камерах. Измеряемые значения отделять от гипотез.

### Деньги и окупаемость

Разовые затраты: платы, серверы, пусконаладка (фикс + на камеру). Три уровня: базовый — существующие камеры/LinQ; расширенный — сигналы у зон; максимальный — громкоговорители/новые камеры. Годовые: поддержка, электроэнергия. Показать **TCO 3 года** и **₽/камеру/месяц**, рядом рыночные ориентиры лицензий/облачных каналов из конфига с источниками и датами.

Каждая выгода — отдельная строка с источником и переключателем:

| Статья | Требование/формула и статус источника |
|---|---|
| Травмы | workers × частота Росстата/1000 × стоимость случая × снижение. Ориентир 1,17/1000 для обрабатывающих производств, Росстат 2025 — **перепроверить первично**, снижение — гипотеза пилота, не обещание Argus |
| Расследование/простой | 3 дня лёгкий / 15 тяжёлый по ст.229.1 ТК РФ — перепроверить смысл и источник; стоимость дня участка задаёт завод, не считать каждый календарный день обязательным простоем без допущения |
| Штрафы | probability_inspection × fine × reduction. КоАП5.27.1 ч1 50–80 тыс., ч4 130–150 тыс. для юрлица — **перепроверить**; вероятность/снижение — допущения |
| Скидка СФР | ФОТ × тариф × доля скидки, до40% по ст.22 125-ФЗ — **перепроверить условия**. По умолчанию **выключена**; Argus сам скидку не даёт |
| Время людей | Сначала часы ОТ/оператора; в рубли только при включённом условии изменения штата или переработок |

Информационная строка СФР, **вне окупаемости**: часть затрат возможно согласовать как предупредительные меры (ориентир до20% взносов, приказ467н, подп.«л» п.3 — проверить актуальный первичный текст). Выплаты фонда не считать экономией завода.

Если выгода покрывает расходы — срок окупаемости. Иначе вместо голого «не окупается»: сколько предотвращённых тяжёлых травм за 3 года достаточно и при какой цене платы LinQ окупаемость за 3 года достигается. Default incident rate — обоснованная подсказка Росстата, не произвольные 4/год. Юридические/статистические числа проверять по первичным источникам; неопределённые оставлять допущениями.

Каждое число и граница формул/окупаемости — тест. Финально проверить весь продукт, текущий API, frontend и Docker после расширения; выполнить содержательное сравнение с **исходным 1.1.0**, не перезаписав baseline новым результатом.
