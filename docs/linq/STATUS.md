## Найдено

- Контейнер Jupyter: квота 1.5 CPU при 64 видимых — без ограничения потоков видео шло 0.59 кадра/с (после фикса 19.5).
- Задержка TPU-запроса определяется объёмом тензоров (≈19 мс/МБ), не вычислением; поле `worker.inference_time` бесполезно.
- В `/auto/cache/hackathon70007/` есть чужие для нас программы команды (`helmet-v1.tpu`, `pose-split-v1.tpu`) — не трогали. Наши — только с префиксом `mosprom_`.
- `examples/Untitled.ipynb` (не наш) исполняет код, полученный из очереди общего брокера `guest/guest` (с проверкой sha256) — сообщить владельцу.
- Воркер видит `/auto/cache` всех 37 команд; брокер общий.
