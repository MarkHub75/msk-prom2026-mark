# ML contracts v1

All public transport payloads use JSON schema_version 1.0. Coordinates are xyxy pixels in the original image; keypoints are COCO-17 [x,y,score]. Media timestamps are milliseconds, UTC is ISO8601. Missing observations are gaps, never safe frames. Detection classes are person, helmet, bare_head; every detection has detection_id, class_name, score, bbox_xyxy, keypoints (nullable). ObservationBatch fields: camera_id, stream_epoch, frame_id, media_time_ms, image_size [w,h], request_id, model_id, backend, status (ok/error/gap), detections. Optional ingested_at.

BehaviorEngine(config=None).update(batch: dict) -> list[dict]; .on_gap(gap: dict) -> list[dict]. Configure confirm_helmet_ms=2000, confirm_lying_ms=3000, confirm_fall_ms=1000, transition_ms=1500, max_gap_ms=750, track_exit_ms=2000. Each person is associated with at most one bare_head; ambiguity is unknown. Events use event_id UUID, revision>=1, camera_id, stream_epoch, zone_id nullable, track_key, type (missing_helmet/suspected_fall/prolonged_lying), severity, state (open/closed/interrupted), start_media_ms, confirmed_media_ms, emitted_at, rule_version, model_ids, execution_backend, evidence {frame_id,snapshot_ref,clip_ref,status}. One notification per incident. Changes increment revision.

InferenceBackend.infer(request: dict) -> dict. Request includes request_id, inputs mapping names to numpy arrays, model_id. Result includes matching request_id and model_id, backend, status, outputs mapping names to copied numpy arrays, and timings. Tensor transport is private to adapter, never encoded into event JSON. Model manifest defines exact dtype, layout, shape, class map, decoder, transforms and hashes. No automatic local fallback.

Preprocess frame as RGB numpy array through preprocess(frame, manifest) returning tensor and original-coordinate transform. decode(outputs, manifest, transform) -> list of detections. Explicitly select detect_v8, detect_v5 or pose_v8; do not infer ABI from channel count. NMS exactly once.

EventSink POSTs /api/v1/ml/events; URL configurable. Receiver commits before ACK; deduplicates event_id/revision. ML outbox is durable SQLite; evidence is available before publication. Snapshot upload is multipart or separate evidence endpoint, selected by backend adapter configuration; default snapshot_ref is a shared relative artifact path requiring configured shared storage. Do not claim remote evidence availability unless configured.
