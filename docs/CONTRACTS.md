# ML contracts v1

All public transport payloads use JSON schema_version 1.0. Coordinates are xyxy pixels in the original image; keypoints are COCO-17 [x,y,score]. Media timestamps are milliseconds, UTC is ISO8601. Missing observations are gaps, never safe frames. Detection classes are person, helmet, bare_head; every detection has detection_id, class_name, score, bbox_xyxy, keypoints (nullable). ObservationBatch fields: camera_id, stream_epoch, frame_id, media_time_ms, image_size [w,h], request_id, model_id, backend, status (ok/error/gap), detections. Optional ingested_at.

BehaviorEngine(config=None).update(batch: dict) -> list[dict]; .on_gap(gap: dict) -> list[dict]. Configure confirm_helmet_ms=2000, confirm_lying_ms=3000, confirm_fall_ms=1000, transition_ms=1500, max_gap_ms=750, track_exit_ms=2000. Each person is associated with at most one bare_head; ambiguity is unknown. Events use event_id UUID, revision>=1, camera_id, stream_epoch, zone_id nullable, track_key, type (missing_helmet/suspected_fall/prolonged_lying), severity, state (open/closed/interrupted), start_media_ms, confirmed_media_ms, emitted_at, rule_version, model_ids, execution_backend, evidence {frame_id,snapshot_ref,clip_ref,status}. One notification per incident. Changes increment revision.

InferenceBackend.infer(request: dict) -> dict. Request includes request_id, inputs mapping names to numpy arrays, model_id. Result includes matching request_id and model_id, backend, status, outputs mapping names to copied numpy arrays, and timings. Tensor transport is private to adapter, never encoded into event JSON. Model manifest defines exact dtype, layout, shape, class map, decoder, transforms and hashes. No automatic local fallback.

Preprocess frame as RGB numpy array through preprocess(frame, manifest) returning tensor and original-coordinate transform. decode(outputs, manifest, transform) -> list of detections. Explicitly select detect_v8, detect_v5, pose_v8 or split_pose_v8; do not infer ABI from channel count. NMS exactly once.

EventSink POSTs /api/v1/ml/events; URL configurable. Receiver commits before ACK; deduplicates event_id/revision. ML outbox is durable SQLite; evidence is available before publication. Current delivery supports shared artifact hosting configured by evidence_base_url; snapshot_ref is a relative artifact path until dispatch. Multipart/upload endpoints are not implemented. Do not claim remote evidence availability unless configured.

Preferred LinQ pose export is split_pose_v8: four already-decoded outputs (boxes, class_scores, keypoint_xy, keypoint_scores) are concatenated/reshaped only on the host. Output tensor names are explicit in split_outputs and mapped to actual runtime names only after ABI verification. Mixed coordinate/confidence pose export failed the quantized-reference smoke and must not be used for behavior deployment.

Events optionally carry execution_records with per-model request_id, backend, program_sha256, status and allowlisted execution_witness. These preserve traceability; execution_backend=linq is not itself independent proof of TPU execution.

Wire-required minimum fields are defined by the JSON schemas and Python validators. request_id, model_id/backend, detection_id/keypoints and full event provenance are populated by the live worker; controlled observation replay may omit optional provenance. Semantic constraints beyond JSON Schema are checked in Python: box ordering/image bounds and event confirmation/end chronology. Boolean values are not numeric IDs, revisions, times or scores. Status error/gap requires empty detections; ready evidence requires a nonempty snapshot or clip reference.
