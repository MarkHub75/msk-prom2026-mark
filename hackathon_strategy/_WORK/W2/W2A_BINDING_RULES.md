## Проверка оригинала, редакции и критических пунктов — K001

### W2A-F01 — новая экстракция совпала с W1

Тип: локальное наблюдение. S02/S07, TEXT_COMPARISON.json. В обоих текстах удалены только пробельные символы; результат сравнения equal=true. Длины до нормализации: W1 39604 символа, W2 39581. Смысловые пункты §§3.6,4,6,7.3,8,10 дополнительно прочитаны. В свежем извлечении по-прежнему есть семь технологических критериев, бесплатные основы, маркировка ИИ, широкий запрет §7.3 и отсылка §8.11 к памятке.

Проверено равенство извлечений, а не равенство PDF-файлов. Один и тот же извлекатель может повторить ту же потерю структуры; это не независимая визуальная верификация. Исходные байты, SHA-256 оригинала, PDF CreationDate/ModDate и полная визуальная сверка отсутствуют.

### W2A-F02 — точный технический предел PDF

Тип: локальное наблюдение. S02. Вместо повторения W1 requests/schannel выполнен urllib с явным TLS1.2 context, отдельной SSL-конфигурацией и timeout25с; получен SSL UNEXPECTED_EOF_WHILE_READING до байтов PDF. Запрос web screenshot для порядковых страниц7,9,11 опять вернул только текстовые ссылки, без image-content. Ни одна страница здесь не объявляется визуально просмотренной. Browser-agent при переходе к PDF сообщил timeout. Это технические ограничения каналов, а не отказ правообладателя.

План закрытия: участник скачивает официальный PDF из реально работающей среды, фиксирует UTC/МСК, URL, Content-Type, размер и SHA-256, сохраняет исходные байты и визуально проверяет страницы7–12 и14 (порядковые страницы, P6–P11/P13 web), где находятся нужные разделы; границы по самому файлу, если изменится вёрстка. Проверить титул, возможные подписи и footers. Полученный файл сравнить с текстами W1/W2. Дату получения не записывать как дату утверждения. Не требуется менять правила команды до получения свидетельства изменения.

### W2A-F03 — FAQ повторно прочитан, независимые изображения не доставлены

Тип: локальное наблюдение + ограничение происхождения. S03. Новый run с capture_config html/screenshots/snapshots воспроизвёл ключевые русские ответы. Его terminal сообщает о выполненных screenshot captures, но содержит только текст; ни image-content, ни URL/байты captures не возвращены. Поэтому достигнуто независимое повторное чтение browser-agent, а требование непосредственного сохранения экранных/HTML-ответов полностью не закрыто.

В terminal есть собственная ошибка английской summary: «7 criteria for tech», хотя расположенный выше список содержит шесть пунктов. Пересказ части ответов сокращён. Английская summary и произвольные «Question» browser-agent не используются как exact text официальной страницы. Для точных русских литералов остаётся W1 FAQ_FULL_TEXT с его прежней оговоркой; новый материал подтверждает предметное совпадение, а не добавляет новую редакцию.

### W2A-F04 — метаданные и публичные связи

Тип: локальное наблюдение. S01/S05. Last-Modified/ETag позволяют повторно сверить ответ сайта; нет оснований объявлять это номером редакции. По опубликованным ссылкам найдены MAX и mts-link.ru.
