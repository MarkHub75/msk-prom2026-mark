- Для каждого сильного кандидата определён точный стартовый ckpt (см. §6 "Каталог"). Класс-таксономия — COCO-80, голова будет переинициализирована при смене nc (по коду transfer, см. F-блок; фактический запуск не делался).

- ONNX готовых Ultralytics-моделей (yolo11*.onnx, yolov8*.onnx, yolo26*.onnx) лежат в assets v8.4.0 (добавлены 2025-12…2026-05) — это артефакты-эталон по структуре графа, а НЕ доказательство совместимости с LinQ. Какой opset и какие параметры экспорта — не извлечено (только размеры/sha из метаданных).
- Не-Ultralytics базы: YOLOX (Apache-2.0-репо; .pth + .onnx в pre-release `0.1.1rc0`), torchvision SSDLite320-MobileNetV3 (COCO, **91-индексная таксономия с N/A**), TF OD API SSD-MobileNet v1/v2 (ссылки живые, HEAD 200), PaddleDetection PP-YOLOE+/PicoDet (.pdparams живые), ONNX Zoo (deprecated, LFS), MIT YOLO (веса только в pre-release v1.0-alpha), D-FINE/RT-DETRv2 (.pth живые).
