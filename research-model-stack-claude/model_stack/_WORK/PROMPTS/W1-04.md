# W1-04 LICENSES — условия использования кода, весов и данных

Роль: исследователь первой волны. Модель: Claude Sonnet 5.5, effort medium. Почему medium: поиск первичных LICENSE, model cards, условий релиза и происхождения данных; требуется точность, а не разбор реализации.

Сначала полностью прочитай `ROOT\_WORK\CONTEXT.md`. Файл результата: `ROOT\_WORK\WAVE1\W1-04_LICENSES.md`.

## Главный вопрос и решение
Какие права и ограничения отдельно на код, отдельно на распространяемые веса и отдельно на обучающие данные относятся к сильным кандидатам — по первичным документам? От ответа зависит выбор пути, если решение будут пилотировать (на сайте: «Лучшие решения будут пилотированы Департаментом инвестиционной и промышленной политики города Москвы»), и что честно сказать жюри/постановщику.

## Что сделать
1. Ultralytics (ultralytics/ultralytics, yolov5, assets): LICENSE (AGPL-3.0?), Enterprise License, распространяется ли AGPL на веса (что именно пишет Ultralytics в первичных документах/FAQ/лицензионной странице), на экспортированные ONNX, на модели, дообученные пользователем. Точные короткие цитаты с URL и датой проверки.
2. YOLOX, PaddleDetection, mmdetection/mmyolo, torchvision (код BSD; веса — отдельные условия?), TF OD API, WongKinYiu yolov7/yolov9, WongKinYiu/YOLO (MIT?), YOLOv10, YOLO-NAS (условия весов), RT-DETR, D-FINE, DEIM, RF-DETR, NanoDet, PicoDet — для тех, что реальные кандидаты.
3. Датасеты, на которых обучены базовые веса: COCO (условия изображений Flickr / CC BY 4.0 аннотаций), Objects365, ImageNet (условия), CrowdHuman. Различай условия аннотаций и изображений.
4. Популярные PPE-датасеты и веса (по мере обнаружения W1-05/W1-16 — их файлы в `_WORK\WAVE1\` можно читать): SHWD, Hard Hat Workers, GDUT-HWD, SH17, CHV, Pictor-PPE, Roboflow Universe (лицензия конкретного проекта), Kaggle-датасеты. Что указано на исходной странице, а что только в перепечатке.
5. Проверь, относится ли лицензия корня репозитория к конкретному checkpoint; совпадает ли карточка на HF с исходным источником; есть ли противоречия.
6. Категории: явно разрешено / опубликованные условия с ограничениями / сведений нет (с охватом поиска) / противоречие. Никаких универсальных юридических выводов.

## Границы
Не делай юридических заключений. Не каталогизируй все датасеты (→ datasets).

## Результат
Карта условий: сущность (код/веса/данные) → документ (URL, версия, дата проверки, цитата) → категория → значение для команды → открытые вопросы. Формат §5 CONTEXT. ID: W1-04-F.., W1-04-S...

Завершение: когда для каждого реального кандидата код, веса и данные имеют отдельный статус с первичным документом или явно описанным отсутствием сведений.
