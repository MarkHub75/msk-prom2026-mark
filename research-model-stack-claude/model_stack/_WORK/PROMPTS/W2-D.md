## Что собрать
1. **Номенклатура и графы** (ultralytics 8.4.184, venv-W1-10): `full`, `raw6-logit`, `raw6-sig`, `raw2-logit` (box `[1,64,A]` + cls `[1,nc,A]`, отдельные выходы), для YOLO26 ещё `e2e`; для yolov8n, yolo11n, yolo26n, yolov5s v7.0 (cut-логиты), **yolov8n-pose / yolo11n-pose / yolo26n-pose** (K005: экспорт `nms=None` и `False`, срез до Conv-выходов box/cls/kpt, numpy-декод точек, сверка с `Results.keypoints`), mobilenet_v2 (torchvision, классификатор). Opset {11, 13, 17/18} — в одинаковом наборе для full и raw (K004). Инвентарь операторов и sha256 каждого. Варианты входа (K025): `uint8 NHWC → Cast → Transpose → Div` в графе и вшитая нормализация в первый Conv — для yolov8n и mobilenet_v2, паритет с базовым графом.
2. **Эталонные тензоры** (K024): ≥20 кадров разных пропорций (COCO-изображения из пакета Ultralytics и открытые кадры людей в СИЗ с понятной лицензией — укажи источник/лицензию каждого), `in_ref_u8.npy`, `in_ref_nchw_f32.npy`, `in_ref_nhwc_f32.npy`, `meta.json` (letterbox-параметры). Сырые выходы PT и ORT для всех графов; отчёт S1/S2 по протоколу W1-11.
3. **Калибровочные генераторы** (K012): скрипт, создающий калибровочный словарь в NCHW и NHWC, диапазоны 0..1 и 0..255, с записанной конфигурацией препроцессинга и sha; таблица «N × размер × раскладка → байты» (memmap как у стенда); список калибровочных кадров отделён от валидационных.
4. **Интроспектор API** (K003): скрипт, который при наличии SDK печатает `dir/help/inspect.signature` для обоих вариантов API (мануал 2025: `QuantizedModel.quantize`, DEFAULT/STAGING; стенд 2026: `RegularModel/calibrate/quantize`, O1/O5) и пишет json; проверка на моках.
5. **Распаковщик `.tpu`**: чтение ZIP + `metadata.json` (`user_order`, `user_dtype`, `scales`) по коду `pytpu` 15.0.24; тест на синтетическом ZIP.
6. **Сценарий первого часа**: порядок подачи графов, критерии классификации отказа (конвертер / квантователь / компилятор / исполнение), что логировать, как сравнивать выход TPU с эталоном (матрица 2×2 W1-11). Оценка времени по шагам.

Попытайся опровергнуть порядок «YOLOv5s cut → YOLOv8n raw → YOLO11/26» (W1-10): при каких фактах SDK он неверен и какой тогда первый граф.
