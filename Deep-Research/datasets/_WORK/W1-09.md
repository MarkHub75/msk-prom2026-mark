# W1-09 — родословные, версии и утечки

Исследователь C; доступ 23.10.2026, Europe/Moscow. Сетевые материалы и API получены в этом запуске. Ниже происхождение, а не заявление об отсутствии дублей. Общая задача и входы прочитаны; работу других ролей не подменяю.

## Практическое решение

Не резервировать CHV для независимого тестирования после обучения на SHWD, а SHD после обучения на SHEL5K. Наличие нового названия не создаёт независимой камеры. SFCHD потенциально полезен как отдельный домен chemical-plant CCTV, но его последовательные кадры и camera-like filenames требуют собственного группового разбиения. Для PhysicalAI нельзя суммировать parent videos и chunks и нельзя считать внешний source-pointer реально полученным видео.

## Установленные цепочки

**W1-09-F01 — заявление автора, SHWD:** положительные helmet-wearing изображения получены Google/Baidu; часть normal-head negatives — SCUT-HEAD. Следовательно, generic head dataset может пересекаться с SHWD. Точная доля/исходные IDs не получены. Не переносить statement о части отрицательных на все 111514 heads.

**W1-09-F02 — прямое авторское происхождение, CHV:** статья §2.3 называет `GDUT-HWD` и `SHWD` источниками изображений CHV. Выбрано 1330 из~10000, заново размечено 6 классов. Это selection+reannotation, а не 1330 заведомо новых сцен. Перекрытие по конкретным basenames/hash пока не измерено: связь семейства установлена, таблицы точных duplicates нет. README более расплывчато говорит Internet/open datasets, но статья даёт точное звено. Само наличие новых vest/color labels не снимает утечку изображения.

**W1-09-F03 — прямое авторское происхождение, SHEL5K:** SHD Kaggle `andrewmvd/hard-hat-detection` → те же 5000 images, расширение 3→6 классов и исправление пропусков → SHEL5K. Mendeley Related Links явно маркирует Kaggle как source. Нельзя складывать 5000+5000 в 10000 уникальных фото. Имена скачанных файлов `hard_hat_workers*.png` и одноимённых XML подтверждают единицу исходного артефакта, но полный байтовый hash cross-parent не выполнен.

**W1-09-F04 — разные сущности:** `SHWD`/`SHW` и `SHD` — не взаимозаменяемые сокращения. Авторский SHWD заявляет 7581 images и hat/person; SHEL5K parent SHD5000 и helmet/head/person. На данном этапе нет доказательства, что все 5000 SHD являются subset SHWD. Не рисовать такую стрелку из похожего имени. Для решения достаточно запретить предполагать независимость до hash audit, но нельзя объявлять конкретное пересечение установленным.

**W1-09-F05 — версия SFCHD:** arXiv2306.02098 v1 03.06.2023, v2 10.08.2024; текущий GitHub PDF оформлен как ACM MM2025. Current commit `7bfabb4533613e6917461dc3758dcff5f304bd03`. README table overview50,558, per-class totals50,559; PDF abstract50,552; наш JSON50,559. Это расхождение версии/подсчёта, не повод создавать три независимых набора. Число SHWD3241 в сравнительной SFCHD-таблице расходится с авторским SHWD7581; происхождение этого subset в текущей проверке не установлено.

**W1-09-F06 — SFCHD временная зависимость, документ:** по статье один кадр каждые 10 frames в течение недели, две chemical plants/~40 scenes. Даже 12,373 уникальных jpg не означают 12,373 независимых наблюдений. JSON image filenames содержат IP-подобные префиксы (`192.168.2.20_...` и др.), которые пригодны как кандидат group key. Это вывод по артефакту, не подтверждённая авторами camera-ID schema. Параметры FPS, непрерывные клипы, wall-clock timestamp и session manifest не получены.

**W1-09-F07 — прямые повторы внутри Git tree, наше наблюдение:** один и тот же Git blob SHA `6c81d4c00b085864d05c5267f2f38988bf63e6b2` лежит в `dataset_SFCHD/sd_train/192.168.2.20_17.jpg` и `dataset_SFCHD/train/person/192.168.2.20_17.jpg`; то же видно для других sample files. Это реально установленные exact-content repeats в служебных sample folders. Они не доказывают дубли train/val полного набора. Не добавлять sample directories как новые данные.

**W1-09-F08 — PhysicalAI parent/chunk:** v1.0, creation date15.06.2026, commit `7f79b39fcd1ef1dc39f23f227cd8a9480d6077db`. Card и provenance различают NVIDIA-generated sources `NV-VAD-v1`, `NV-VAD-v1.1`, `NV-Retail-Shoplifting-v0.1` и external `CHAD`,`VAD-R1`. Всего 1612 parent annotation records/3796 labeled chunks, но media payload содержит только 1486 generated parent videos/2939 clips (2919 labeled+20 unlabeled). Chunks — производные тех же parents, не независимое расширение числа сцен. Файлы global `video_00001.mp4` не кодируют источник; join по manifest/dataset/video_id обязателен.

**W1-09-F09 — PhysicalAI условия независимости:** card прямо предупреждает о похожих generation scenarios и рекомендует scenario split. Train-only; отдельного official validation/test нет. Видео генерировались Veo3/Cosmos3 Super; labels hybrid/automated/manually corrected. Не считать их real CCTV holdout. External media не распространяются этим payload, поэтому наличие annotation rows не означает получение CHAD/VAD-R1.

## Что не установлено

- Точное пересечение CHV↔SHWD/GDUT-HWD: нужна таблица соответствий изображений.
- SHD↔SHWD: нельзя ни подтвердить полную независимость, ни объявить subset без сравнения.
- SH17/Pictor/CPPE lineage здесь не расследованы повторно: см. владельцев W1-02/04/05/11/14. Общие internet sources создают риск, но конкретные повторы не доказаны.
- Roboflow/HF переупаковки helmet datasets намеренно не приняты как independent originals: для решения уже доступны авторские sources. Для любого выбранного export нужно отдельно сохранить owner/project/version/export map и выполнить exact/near comparison.
- Новые заводские видео Önal/Dandıl и SARD переданы оркестратором из A; считаются адресной зацепкой, а не независимо проверенным C материалом.

## Предложенная проверка W1-09-E01

Входы: точные parent/derived image manifests и доступные images; версии как выше. Сохранить SHA256, perceptual hash, исходное имя, source family, transformation history. Сначала exact SHA; затем near match с ручной проверкой resize/crop/flip; отдельно scene/camera/time grouping. Для переаннотации удерживать image group целиком в одном split, сохранять обе annotation revisions. Результат: matched pairs и причина совпадения, а не просто число исключённых файлов. Успех hash audit не доказывает независимость разных кадров одного видео; потребуется session/scenario grouping. До проверки CHV/SHWD и SHD/SHEL5K объединять только в training pool, не заявляя независимый cross-dataset benchmark.
