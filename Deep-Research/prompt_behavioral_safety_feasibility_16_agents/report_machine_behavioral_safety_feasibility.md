## YOLOX nano: exact graph, raw decoder and unresolved preprocessing

**[local-observation] First custom detector candidate:** [official `yolox_nano.onnx`, release `0.1.1rc0`](https://github.com/Megvii-BaseDetection/YOLOX/releases/download/0.1.1rc0/yolox_nano.onnx), full **3,659,407 bytes**, local SHA256 `c789161ed43c8269fcd4e67c67eeeb4e80c622da2eb296a20bc6007bd18a0b7d`. A ready ONNX avoids a PT export for the first trial. Code Apache-2.0 and official-release provenance are positive evidence; explicit standalone weight grant was not found, so public binary/compiled scope remains an action-specific question. [S034](SOURCES.md#S034), [F036](RAW_FACTS.md#F036), [F015](RAW_FACTS.md#F015).

**[local-observation/source] Actual graph:** IR 6, opset 11, FLOAT `images[1,3,416,416] → output[1,3549,85]`; 369 nodes/236 initializers. Conv, Sigmoid, Mul, Concat, Slice, Add, MaxPool, Reshape, Resize, Transpose; no Exp/NMS/external data. Concat/transpose ending plus `decode_in_inference=False` supports raw geometry: host grids stride 8/16/32; `xy=(raw_xy+grid)*stride`, `wh=exp(raw_wh)*stride`, score objectness × class. Decode geometry once; obj/classes are already sigmoid, so do not sigmoid again. `person=0`, `cell phone=67` are contiguous COCO positions, not native category IDs 1/77. This is graph/source matching, not recovered exact export-command provenance. [F037](RAW_FACTS.md#F037).

**[source/inference] Historical preprocessing is unresolved, not silently fixed.** Tag `0.1.1rc0` → `e1052df71842031413f6030723c3607b839c80ce` (2021-08-12) uses RGB, `/255`, ImageNet mean/std; asset was created 2021-08-18; release body announces normalization removal/incompatible old weights on 2021-08-19. Current pinned README `6ddff4824372906469a7fae2dc3206c7aa4bbaee` points to the same asset with BGR 0…255. Shape does not encode color. Neither historical normalization nor current BGR is an empirically artifact-matched golden. [F038](RAW_FACTS.md#F038).

**[proposed] Freeze test reference `YOLOX-N416-BGR-v1`** from [pinned current caller](https://raw.githubusercontent.com/Megvii-BaseDetection/YOLOX/6ddff4824372906469a7fae2dc3206c7aa4bbaee/demo/ONNXRuntime/onnx_inference.py): OpenCV BGR uint8; `r=min(416/H,416/W)`; INTER_LINEAR resize to `int(W*r),int(H*r)`; pad 114 on right/bottom only, image top-left; CHW float32 batch 1, no RGB swap, `/255` or normalization. Decode above; xyxy divided by `r`, no central-pad subtraction. Current NMS is class-agnostic argmax, `score>.1`, IoU `<=.45`, `+1` area; parser `.3` is visualization. These are comparison-recipe values, not production thresholds. Save raw output before in-place decode, input/tensor hashes, geometry and contract version. [F039](RAW_FACTS.md#F039).

Before PTQ, meaningful host sanity on preselected permissioned non-square/color/edge/negative controls must establish perception and geometry. A predeclared legacy diagnostic is allowed; do not tune recipe on test results. CPU↔LinQ agreement on the same incorrectly prepared tensor does not prove correct perception. [Q005](OPEN_QUESTIONS.md#Q005), [E002](OPEN_QUESTIONS.md#E002).
