Дата доступа: **23.10.2026**. Ветка выполнена как research, без приложения, обучения, инференса, экспорта или обращения к LinQ. Авторские скрипты не запускались. Прочитаны задание `_WORK/PROMPT_W1-11.md`, визуальные наблюдения оркестратора `_WORK/CASE_ROOT_NOTES.md` и релевантные W1-04/05/06/07. Это notes, не извлечённый текст растрового PDF. **Вопрос/польза:** какие реальные артефакты помогают закрыть малые признаки для 2–3 сценариев MVP, а какие создают ложное ощущение готовности? Ниже даны пути до labels/video/weights и точная семантика вместо ещё одного общего описания detector→tracker→rule.

Обозначения: **D** — первичный документ/условия; **A** — лично прочитанный код/metadata/разметка; **C** — утверждение автора; **I** — инженерный вывод; **P** — невыполненный план; **U** — неизвестно. Все F/S ID локальны этой ветке.

## 1. Решение для выбора сценариев

**W1-11-F01 / I.** Из исследованных редких признаков **видимый огонь/дым** имеет наиболее прямую артефактную цепочку: object labels D-Fire + конкретные веса из W1-05 + новые публичные видео FIRESENSE/FURG. Это отдельный сценарий от курения: сигаретный жест/сигарета не равны пламени/дымовой области. Данные всё ещё не доказывают событие «вне разрешённой зоны» без заданной политики камеры.

**W1-11-F02 / I.** Для phone use появились настоящие person-action labels AVA, точные действия NTU и готовый AVA SlowFast checkpoint. Но это существенно более сложный pipeline, чем COCO phone bbox. Для короткого MVP телефон остаётся условным сценарием только при подходящем target-video; AVA — полезный donor/replay candidate, не готовая промышленная проверка.

**W1-11-F03 / I.** Курение, высоту без пристёгивания и полное перелезание не следует обещать как готовые универсальные сценарии. У курения есть image classification и action labels, но нет проверенного полного industrial-video события. У harness — наличие/видимое отсутствие не соединение с анкером. У нового fence-источника найдена **реальная перестановка class IDs между поднаборами**, а опубликованный custom checkpoint не подтверждён. Путь к локализованному исследованию есть; короткой замкнутой цепочки до LinQ пока нет.

Пригодно как будущий action donor/постановочные confusers, непригодно как немедленный свободный video bundle или открытая лицензия «на всё».

## 3. Курение: action, cigarette и дым разделены

### W1-11-S04 — Mendeley Smoker v1: доступные изображения с нужными confusers

[Первичная карточка j45dj8bgfc/1](https://data.mendeley.com/datasets/j45dj8bgfc/1), Ali Khan,15.08.2022, DOI10.17632/j45dj8bgfc.1, CC BY4.0. **W1-11-F08 / D:** карточка задаёт 1120 картинок250×250: `Smoking`560/`NotSmoking`560. Заявлены web-search изображения и похожие жесты non-smokers: питьё, ингалятор, телефон, кашель. Source numeric IDs не задаются: сортировка папок конкретным loader может поменять индекс. Данные image classification; карточка не даёт cigarette boxes, person tracks или timestamps. Сам архив в этой ветке не скачан; соседний datasets сообщает свой полный decode, это не повторённая проверка.

Условно usable для crop classification/ручной подборки жестовых negatives. Неusable как видео для события, для оценки tiny cigarette в full-frame CCTV или доказательство industrial quality. Resize250×250 уже изменил масштаб/контекст: crop accuracy нельзя переносить на 1920-wide кадр с маленьким лицом. Карточка CC BY не подтверждает очищенные права каждого найденного поиском фото/публичного demo. Для демонстрации предпочтительнее собственные/организаторские разрешённые кадры.
