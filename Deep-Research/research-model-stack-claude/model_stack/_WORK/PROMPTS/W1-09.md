## Главный вопрос и решение
Какие зафиксированные окружения (Python, torch, CUDA, onnx, onnxruntime, onnxslim/onnxsim, пакеты фреймворка) нужны для обучения, экспорта и проверки каждой сильной цепочки, где есть custom CUDA ops или компиляция расширений, и как быстро установить свойства реальных машин команды? От ответа зависит, успеет ли команда поднять рабочее окружение в первые часы и не столкнётся ли с несовместимостью training- и export-окружений.

## Что сделать
1. Ultralytics: `pyproject.toml` текущей версии (требования к python, torch, torchvision, opencv; extras `export`), какие пакеты ставит exporter для ONNX (`onnx`, `onnxslim`, `onnxruntime`) и какие версии ограничивает (`check_requirements` в `exporter.py`) — с commit. Официальный Docker (`docker/Dockerfile*`, образы ultralytics/ultralytics на Docker Hub — теги).
2. PyTorch: актуальная стабильная версия на 2026-10, поддерживаемые CUDA (cu118/cu121/cu124/cu126/cu128/…) по https://pytorch.org/get-started/locally/ и previous-versions; поддержка Ada (RTX 4070, sm_89) — из первичных источников; Windows vs Linux; Python 3.13 поддержка; `torch.onnx.export` TorchScript-based vs `dynamo=True` экспортер — какой по умолчанию в текущей версии (важно для W1-10; ссылку на docs/stable зафиксируй с версией).
3. ONNX / ONNX Runtime: версии, поддерживаемые opset (https://onnxruntime.ai/docs/reference/compatibility.html), IR version — что может понадобиться компилятору LinQ (неизвестно — сформулируй вопросы → linq_platform).
4. YOLOX: `requirements.txt`, `setup.py` (собирает ли C++/CUDA расширения? `yolox/layers/fast_coco_eval_api`, `cocoeval`), проблемы установки на новых torch/py.
5. PaddleDetection (PaddlePaddle GPU колёса, CUDA), mmdetection (mmcv с compiled ops, MIM, совместимость mmcv 2.x с torch 2.x) — кратко, насколько реально для 45 часов.
6. Что нужно установить про машины команды (команды диагностики: `nvidia-smi`, `nvcc --version`, `python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available())"` и т.п.) — список проверок, не выдумывая конфигураций.
7. Предложи 2–4 зафиксированных окружения (training-GPU, export-CPU, reference-ORT, при необходимости отдельное для YOLOX/legacy yolov5) с точными версиями и источником каждой версии. Для LinQ-SDK окружение неизвестно — укажи, что нужно узнать.

Допустимо: создать в SCRATCH venv и выполнить `pip download`/`pip install --dry-run`/`pip index versions` для проверки разрешимости зависимостей (local_observation), без установки тяжёлых CUDA-колёс без надобности.
