## Решение

Допуск относится к **конкретной паре артефактов и области входов**, а не к формату ONNX или названию архитектуры. Сохранять пять самостоятельных заключений: **source/provenance, tensor parity, task quality, event/alert quality, device execution**. Компиляция без ошибки не заменяет остальные доказательства. «Не нашли значимого различия» не означает «эквивалентны»: команда заранее задаёт риск, допустимый проигрыш и требуемую точность оценки. При нехватке данных вердикт **HOLD/INCONCLUSIVE**, а не PASS. У smoke область доказательства уже, чем у полного quality gate. Это предлагаемый протокол, не официальная метрика кейса.

PDF в этой ветке повторно не рендерился. SDK, веса, доступ, GT, эталонные tensors и реальный evaluator не предоставлены.

## Факты и практическое значение

**W1-12-F01 — CODE, S02 `collect_activations` L115–165.** Без явных опций выбираются `ORT_DISABLE_ALL` и `CPUExecutionProvider`; input reader используется для сбора augmented outputs. Этот debug CPU-path не доказывает выполнение production graph или TPU. Логировать provider/опции и отдельно проверять нетронутый целевой artifact.

**W1-12-F02 — DOC, S01 Quantization Debugging.** ORT предлагает сравнивать соответствующие веса/активации; graph optimization во время quantization затрудняет соответствие. Фиксировать graph до/после преобразования и первую наблюдаемую расходящуюся границу, не называть весь эффект «INT8 потерей».

**W1-12-F03 — CODE, S03 `Params/evaluateImg/accumulate`.** Bbox defaults: IoU .50:.05:.95, 101 recall points, maxDets 1/10/100; per-image matching score-ordered, aggregation pooled; без GT sentinel −1. Это не mean frame precision и не произвольный Hungarian. Pin evaluator/config; при bootstrap пересчитать pooled AP; для пустого класса отдельно показать FP/exposure.

**W1-12-F04 — CODE, S03 `computeOks/setKpParams`.** OKS использует GT area, visibility `v>0`, per-keypoint sigmas; стандартный профиль 17 точек. Согласовать skeleton, order, visibility, scale, sigmas для RTMPose/custom pose; произвольный skeleton не оценивать молча как COCO17.

**W1-12-F05 — DOC, S04 description.** Для одинаковых scores PyTorch не гарантирует одинаково выбранный overlapping box на CPU/GPU. Raw tensor parity и set matching нужны отдельно от сравнения индексов NMS; tie-case логировать. Это не оправдание missed critical event.

**W1-12-F06 — CODE, S05 `eval_sequence/_compute_final_fields`.** HOTA разделяет DetA/AssA; matching сочетает global association alignment и local similarity. Число/строки track IDs не доказывают tracking quality; нужен независимый GT continuity. HOTA не измеряет timely delivery.

**W1-12-F07 — DOC/CODE, S06 paired/Notes; S07 L214.** `paired=True` переиспользует индексы для массивов; BCa может дать NaN при вырождении. Индекс должен означать допустимый cluster, а не соседний кадр. NaN и undefined draws раскрывать; увеличение resamples не добавляет камер.

**W1-12-F08 — PUB, S08 Introduction/VI.A/C.3.** Внутрикластерная корреляция способна занизить обычные standard errors; при few clusters асимптотика и некоторые bootstrap остаются ненадёжны; важны degenerate draws и чувствительность к clusters. Camera/site/episode dependence важнее числа frames. Wild regression bootstrap автоматически не переносится на AP/event matching.

**W1-12-F09 — DOC, S09 Advanced usages.** LiteRT различает local float/quant op comparison при общем предшествующем quantized input и whole-model verify разделённых моделей; доступны layer/model metrics. «Ошибка слоя» зависит от его входов; debug artifact не заменяет production. Internal APIs помечены нестабильными. Selective quantization может фрагментировать accelerator execution и увеличить transfers.

**W1-12-F10 — secondary local / UNKNOWN, S10.** Кейс требует LinQ и полезных уведомлений; универсального процента деградации нет. Device evidence в нашей ветке отсутствует. До связанного artifact/completion/device trace статус device=UNVERIFIED.

## Входы и измерения

Три роли данных: calibration; development/threshold/debug; untouched evaluation. Повторно используемый golden smoke — диагностический, не скрытый test. Split по происхождению: одно видео/эпизод, соседние frames, нарезки и синхронные камеры общего инцидента не пересекают holdout без явно иной цели. Camera-heldout для новых ракурсов; site-heldout для площадок. Frame split не создаёт независимость.

Golden pack **не получен**. Предлагается: positives/empty frames, small PPE/phone, multi-person ownership, occlusion, hard negatives, lighting, boundary crossing; continuous clips short event, re-entry/reset, ID switch, file-end/outage, ongoing incident/duplicates. Immutable IDs/provenance/license; synthetic явно synthetic. Smoke информативен, но не репрезентативен.

A/B должны иметь те же decoded frames/source sampling, crop/resize/pad/color/normalization/ROI, batch/shapes, class/skeleton map, score threshold/NMS/caps, tracker/rule/zone versions, resets/order/evaluator. Retuning на test не является изолированным эффектом quantization. Разрешённый retuning на development — отдельная система с новым policy hash.

### Tensor, detection, pose

1. Проверить наличие всех outputs, names/shapes/dtypes, batch indexing, valid coordinates, finite values и non-mutated inputs. Хеш сравнивать **на inference boundary**, не только у JPEG. Для INT8 входа хранить master float tensor и quantized bytes+scale/zp, проверять declared mapping, а не требовать одинаковые bytes разных dtype.
2. Для соответствующих `r,c`: absolute error, normalized RMSE с объявленным scale/epsilon, p50/p95/p99/max и его координата, per-channel/head/slice summaries. Возможное условие `abs(c-r)<=atol_j+rtol_j*abs(r)`; tolerances согласуются на dev по repeatability/dtype/head sensitivity. Универсальные `1e-3`, cosine/SQNR cutoffs не предлагаются. NaN/Inf — отдельный contract failure; cosine не определён на нуле и может скрыть локальную ошибку.
3. Сравнить pre-threshold scores/logits/boxes/keypoints и threshold-margin crossings. Малая численная ошибка может дискретно менять событие. Первая observable divergence — локатор, не доказательство причины внутри fused op.
4. Canonical decode outputs сравнивать **как множества**: class-consistent IoU edges, one-to-one maximum cardinality, затем максимум sum IoU, stable tie-break. Хранить пары/unmatched A/B, score/box/keypoint deltas, ties. Это diagnostic matcher, **не COCO evaluator**.
5. Независимые A→GT и B→GT: per-class/size/condition AP и precision/recall при frozen threshold; negatives/empty scenes. Pose — подходящий OKS и visible per-joint error/PCK с определёнными normalization/threshold; unknown/hidden и unmatched persons отдельно. B≈A не делает ошибочный A правильным.

### Tracking и events

Числовые track IDs не обязаны совпадать. A/B оцениваются относительно независимого GT person/episode roster с continuity/occlusion/re-entry/reset. HOTA/DetA/AssA, ID switches/fragments — отдельный отчёт. Два replay: (i) одинаковые source schedule/downstream, меняется prediction stream — model effect; (ii) фактическое расписание/delivery/load — operational effect. Их смешение скрывает sampling/queue проблему под quantization.

GT episode определять по camera/epoch/person-or-scene/type/zone, observable onset/end и sufficient causal evidence. Короткий эпизод не превращать в N independent positive frames. Useful-alert edge требует совместимые ключи/личность, consumed evidence и deadline D в общей elapsed-time шкале; active-at-delivery либо after-event reporting — отдельное заранее выбранное правило. Freeze one-to-one matcher/tie-break. Duplicates, late, wrong-person/type, after-end, unresolved сохранять отдельно от strict unmatched. GT нельзя порождать тестируемым tracker/cooldown.

Только для **общего complete closed universe**: TP=#matches, FN=#GT−TP, FP=#delivered−TP; timely critical recall=TPcritical/NGTcritical. При разных boundary cohorts TP precision/recall может отличаться — общий F1 недопустим. Нужны sufficient follow-up и delivery close; incomplete logs/censored events не превращать в успех. Onset uncertainty хранить interval, не midpoint. Latency quantiles показывать с n и misses/late/unresolved: success-only p95 страдает survivor bias.

Semantic false delivered records/source-camera-hour = adjudicated false visible records / union duration заявленных source intervals по камерам в часах. Для этого нужен полный delivery census и review каждого assertion; recall дополнительно требует независимого GT discovery, включая silence. Duplicate burden отдельно. Не делить на positive clips, wall replay hours или только обработанные frames без другого имени endpoint. Outage при полном GT/logs — operational miss. Нет универсального TN/camera-hour определения specificity.

## Парная uncertainty и acceptance contract

До evaluation задать population (fixed corpus либо новые камеры), primary endpoints, допустимые losses δ, абсолютные floors/caps, alpha/one-sided bounds, critical slices, budget/stop rule. Полностью просмотренный fixed corpus с полными deterministic A/B имеет наблюдаемую разницу; bootstrap не нужен, чтобы сделать её «реальной», и не расширяет corpus на будущие заводы.

Для higher-is-better `Dq=qB−qA`: non-inferiority PASS при `L(Dq)>=−δq` и absolute floor B. Для lower-is-better `Dc=cB−cA`: `U(Dc)<=δc` плюс absolute cap. Для **двусторонней equivalence** весь CI внутри заранее заданных `[−δlow,+δhigh]`; это иной, более сильный вопрос. Недостоверный CI не даёт PASS. CI пересекает допустимую и недопустимую области → INCONCLUSIVE. Нарушен hard invariant/подтверждён budget violation → FAIL. Незаполненные δ/floors/caps → HOLD, не «1% по умолчанию».

Возможен узкий **PASS(fixed golden fixtures)** с нулём новых пропусков по frozen critical roster; это engineering invariant, не будущий recall=100%. Baseline ниже absolute floor нельзя одобрить за fidelity.

- Сохранить эпизодные A+/B+, A+/B− (regressed), A−/B+ (improved), A−/B−, unknown/incomplete; counts/denominators по cameras/classes/exposure/positive episodes/groups.
- Выбрать релевантный независимый cluster: site, camera-session или общий incident, объединяя связанные камеры. Для fixed-camera temporal claim блоки/эпизоды требуют обоснования границ зависимости. Hierarchical camera→episode resampling — только под соответствующий design. Миллион adjacent frames не равен миллиону trials.
- В каждом paired cluster-resample выбирать одинаковые clusters для A/B/GT; пересчитать **весь** pooled AP, TP/GT ratio, event matching, false/exposure, quantiles. Копии повторно выбранного cluster namespace по GT/person/event IDs. Mean per-camera AP вместо pooled AP меняет estimand.
- Сохранить RNG/software/draw count/scheme/weights/units, undefined/zero-positive fraction, histogram и leave-one-cluster-out sensitivity. Undefined recall нельзя молча удалить. BCa может выродиться; percentile [0,0] на нулевых ошибках не доказывает zero risk. При few clusters — descriptive sensitivity, HOLD generalization и сбор других камер/смен; магического minimum N нет.
- Overlap отдельных CI не является CI разности. `p>0.05` равенства не доказывает non-inferiority. McNemar без cluster model не исправляет видеокорреляцию; AP/latency не binary outcomes. Повторы deterministic inference проверяют nondeterminism, не добавляют камер.
- Primary endpoints/slices freeze; exploratory post-hoc findings подтвердить новым holdout. Все required gates должны пройти; для simultaneous coverage нескольких CI заранее выбрать multiplicity procedure. Подбор лучшего candidate на test создаёт selection optimism.

## E-ID: дешёвые → средние → дорогие

Все **NOT RUN**. FAIL — нарушение; HOLD — нет входа/доступа/согласованного порога; INCONCLUSIVE — недостаточно данных для заявленного допуска. Все три останавливают продвижение. LinQ команды не приводятся: SDK/API неизвестен; чужой runtime его не заменяет.

### W1-12-E01 — Source contract и export same dtype

**Входы:** checkpoint/config/source commit/class/skeleton map; immutable sample IDs known-positive, empty, small-object, multi-person; tensors/transforms; source runtime/export graph/log. Stages: checkpoint versus same-dtype export reference runtime.

**Процедура/логи:** lineage/eval/shapes/dtypes; replay exact tensors; named raw outputs, finite masks/error maps/complete sample census. Actual versions/options/device, hashes/stderr/errors per sample. Не выбирать output по первой позиции; unsupported shape отметить.

**PASS:** contract и agreed tolerances соблюдены на roster. **FAIL:** class/output semantics/batch indexing/nonfinite/tolerance failure. **HOLD:** нет baseline/tolerances. Локализовать preprocessing/export/head, rollback candidate до PTQ. **Не доказывает:** GT accuracy, LinQ, другие shapes/dtypes.

### W1-12-E02 — Изоляция dtype / quant / compiler

**Входы:** E01; graph/transformation manifest, calibration IDs отдельно от eval, quant scale/zp/axis/effective flags; compiler/runtime, доступные intermediate dumps. Sample IDs E01+hard/threshold-margin fixtures.

**Процедура/логи:** один изменённый этап где возможно; paired tensors на доступных границах; обычный artifact сохранить до instrumentation. Снять raw outputs production artifact отдельно от augmented debug, per-channel/head errors, graph/compiler hashes/options/fusions/name mapping/fallback, first divergence и unavailable boundaries.

**PASS:** observed-transition и source-to-final budgets соблюдены; debug не подменяет production. **FAIL:** contract/budget violation. **HOLD** attribution при отсутствии float target; конечная GT проверка всё равно возможна отдельно. Проверить calibration saturation, quant params, unsupported/fused ops; rollback к accepted boundary. **Не доказывает:** локализацию внутри fused kernel, event quality, поддержку LinQ mixed precision. ORT debug по умолчанию CPU (F01).

### W1-12-E03 — Independent GT detection/pose regression

**Входы:** A/B outputs, untouched grouped GT/policy, exact decoder/geometry/NMS/evaluator; positives/negative exposure/size/occlusion/light manifests; acceptance limits до прогона.

**Процедура/логи:** diagnostic A↔B matches; один evaluator A↔GT/B↔GT; predictions/matches/unmatched reasons, per-class/slice AP и frozen-threshold TP/FP/FN, pose metrics/denominators; paired Δ с uncertainty по sampling design. Cap/maxDets/ignore/ties/GT unknown/empty classes/per-group census.

**PASS:** absolute floors/caps, primary non-inferiority bounds и critical invariants. **FAIL:** новый miss must-pass critical fixture или установленный budget violation. **INCONCLUSIVE:** wide CI/few groups/нет positives обязательного класса. Precision/calibration/threshold repair только на dev с новым policy ID. **Не доказывает:** event utility, hidden attributes, natural-stream precision из balanced clips.

### W1-12-E04 — Causal tracking/rule/event replay

**Входы:** continuous clips/PTS/epoch, independent person/episode GT и complete follow-up, A/B predictions, frozen tracker/rules/zones/reset. IDs: short event, occlusion/ID switch, wrong-person ambiguity, reset/re-entry, long ongoing и file-boundary.

**Процедура/логи:** одинаковый source schedule/downstream/reset/warm-up; сохранить state transitions/consumed frames/associations/event proposals; independent matcher; timely critical recall, duplicates/wrong-person/type/timing, association metrics, A-only/B-only outcomes, config hashes.

**PASS:** agreed event budgets/invariants с complete counts/exposure. **FAIL:** invariant miss/duplicate, evidence-free backdating, изменён downstream. **HOLD/INCONCLUSIVE:** incomplete GT/onset/follow-up. Oracle replay с одинаковыми GT detections либо frozen predictions локализует detector versus downstream, не выдаётся за production. **Не доказывает:** delivery/network/load/target device.

### W1-12-E05 — LinQ artifact и полезная доставка

**Входы:** реально выданный service/server+interface, supported artifact/source lineage/hash; E01/E03 frames и E04 clips server-side, **если** file/upload путь поддержан. Способ custom-model upload/raw outputs установить по выданному интерфейсу; stream с ноутбука не предполагается обязательным.

**Процедура:** smoke→hard regression→continuous replay. Связать sample/job/model/artifact IDs с completion/output и visible alert. Снять доступные device/compile/partition/profiler/fallback evidence; измерять завершение, не enqueue. Разные clock domains не вычитать без mapping. Scheduled/processed/dropped frames, input age/failures/timeouts/drain/post-close replies отдельно.

**Выходы/логи:** E03/E04 на реально возвращённых outputs; completeness; p50/p95/p99 с названием latency boundary/n, timely recall+misses, false/duplicates/source-camera-hour; submit/start/complete, source anchors, receiver delivery, retries/late/queue ledger; доступная TPU attribution/CPU portions. Никаких выдуманных profiler API.

**PASS:** связанные lineage/completion/device evidence и agreed quality/completeness/latency под declared concurrency; drops/uncompleted включены. **FAIL:** другой artifact/shape, hidden fallback вопреки требованию, потерянные outputs/events, budget violation. **HOLD:** interface не раскрывает target proof; записать ровно подтверждённое service и неизвестное. **Не доказывает:** весь graph на TPU без partitions, другие N streams, будущую безопасность.

### W1-12-E06 — Reviewable regression report и rollback

**Входы:** immutable baseline/candidate bundles, E01–E05, versioned acceptance contract/approver/date, rollback bundle model+decoder+preprocessing+policy.

**Процедура/выходы:** sample/job census, adjacent/source-to-final deltas, CI/limits, primary/critical slice table, worst regression IDs/визуализация, unmatched/drop ledger, device links. Сохранить FAIL/HOLD/negative results и baseline. Откатывать весь согласованный bundle; weight-only rollback может не восстановить поведение.

**PASS:** все required gates завершены/прошли в declared scope, решение воспроизводимо из artifacts. **FAIL:** любой required failed; **HOLD:** missing/inconclusive. Limited smoke PASS явно не full acceptance. **Не доказывает:** production release/сертификацию. Новый dtype/shape/compiler/runtime/decoder/classes/camera geometry/rule/sampling открывает соответствующие gates заново.

## Диагностика и stop-loss

| Симптом | Дешёвая проверка | Ограничение |
|---|---|---|
| Исчезли detections | input hash/dtype/range/layout, output count/semantics, score activation/threshold | QAT до контракта не нужен |
| Boxes смещены/зеркальны | одинаковый raw output одним decoder; xyxy/xywh/normalization/pad/inverse transform | Хороший tensor не гарантирует geometry |
| Классы перемешаны | class hash, score axis/nc, synthetic per-class fixture | COCO84/85 не универсальны для custom nc |
| Малые tensor deltas, разные NMS/events | margins/ties/caps/order, set matching, downstream state replay | Row mismatch не обязательно quantization damage |
| Общий AP сохранён, small/pose/event хуже | critical size/joint/occlusion slices, paired downstream | Средний AP не закрывает critical gate |
| Source/export проходят, target нет | input bytes/quant params/output map/completion/device, first observed boundary | Без target intermediates причина partly UNKNOWN |
| Real replay хуже frozen | source sampling/drops/age/resets/overload/retries | Throughput не равен временной coverage |

Первое нарушенное required invariant останавливает переход. Сохранить failed bundle и minimal reproducer ID. Сначала contract/geometry/decoder и observable transition, затем calibration/precision repair на dev. Обучение/QAT — отдельное решение после локализации с ресурсным budget; в этой ветке не запускается. Если observability не разделяет причины, честно записать confounded edge.
