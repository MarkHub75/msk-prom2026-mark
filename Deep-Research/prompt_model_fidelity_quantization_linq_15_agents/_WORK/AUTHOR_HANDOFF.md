## Обязательные precise literals и corrections

- `onnxsim v0.4.36 check_n=0` может дать check_ok без inference comparison; `rtol=1e-4/atol=1e-5` — defaults checker, не budgets кейса. PyTorch2.9 internal verification `5e-3/1e-1` arbitrary warning thresholds, не acceptance. Сохранять фактически выбранный exporter: PyTorch new default dynamo не Ultralytics legacy helper.
- onnxconverter-common1.16.0 clipping defaults `min_positive_val=1e-7`, `max_finite_val=1e4` — policy конвертера, не предел FP16/допуск. `keep_io_types=True` не all-internal FP32. BF16 больше range, грубее mantissa, не universally more accurate. Fusion может улучшать локальную точность и менять rounding; deviation не автоматически quality loss.
- ORT1.22.0 factory Percentile99.999 против docstring99.99; NNCF `MIXED` — symmetric W/asymmetric A, **не FP16/INT8**; NNCF per-sample quantile+aggregation отличается от ORT pooled histogram. MSE-calibrator API generic не установлен в рассмотренных selectors; tensor MSE diagnostic не имя LinQ функции.
- `args.output_tensอร์_name` — точная Unicode typo pinned стороннего runner, не SDK defect. `normalize_prediction_shape`84/85, first ndarray rank≥3 и COCO80_TO_91 не custom class adapter. Не заявлять actual AttributeError execution: это static code inference. Vendor TinyYOLO3 — другой artifact/layout/input/decoder, не self-build YOLOv8s.
- Ultralytics8.3.230 обычный no-NMS Detect `output0[B,4+nc,A]`, Pose `output0[B,4+nc+K*D,A]`: уже DFL/box decode/class sigmoid; нет objectness. Nc1/2/3 дают C5/6/7, Pose17×3 C56/57/58, A8400 только для конкретного640+strides8/16/32. Правильный layout BCN; ошибочный BNC lastdim6 может пройти early final-detection shortcut, explicit nc/end2endFalse не выключают shortcut.
- NMS mutates coordinate view in-place: raw dump/copy до вызова. Sys.modules torchvision меняет NMS branch; ties/strict `>`/time-limit/caps/padding явно. Core/graph/external NMS не автоматически эквивалентны. ONNX NMS outputs `[batch,class,box]` int64 indices, default max_output_boxes_per_class0 — ни одного selected, а не N×6 boxes.
- G01 source853×481→640: resize640×361/pads0,139,0,140; auto stride32→640×384/pads0,11,0,12; pose point pad≈139.5545 vs box139, source discrepancy≈.7390625 px — аналитика, не model drift. v8.3.230 matrix включает `same_shapes&&rect&&(pt||(dynamic&&!imx))`; Model.predict rectTrue может override default.yamlFalse. Low-conf xy не zeroed в new code; stale docstring не implementation.
- LinQ guide signature/prose platform `64x64_fpga`/`128x128_asic` discrepancy **в extracted text**; PDF visual original не проверен, не называть доказанным manual bug. Explicit compile `TPU_128x128_PARAMS` не чинит отдельный default as_graph. Одно присваивание return не доказывает, что return не tuple. O1=DEFAULT/O5=STAGING не установлены.
- Calibration N axis не compile B. First sorted500/chunk128 — client defaults, не vendor recommended dataset/RAM guarantee. Bare Uint8 pointer означает bytes address, не numerical INT8; `view(user_dtype)` — reinterpretation, не dequantization. FULL=user IO не автоматически добавленный rescale. RAW mode0/PRE1/POST2/FULL3 и RAW program absence user_dtype — разные вещи; старый Codec требует `tpu_tlm_is` и не доказывает current availability.
- ByteTrack/BoT-SORT `frame_id+=1`, Kalman `dt=1`, frame_rate меняет buffer; передать1 не PTS-aware tracker. ByteTrack interpolation использует future endpoint, не online alert. ReID — дополнительная NN, её target evidence отдельно. Source PTS/timebase не UTC/monotonic; equal track ID numbers не quality criterion.

## Restoration/stop-loss D и режимы доступа

1. Нет source или grant→Q001–Q003, approved scope; catalog-only ограничивает fidelity claim, но independent service quality возможно.
2. Source repeatability FAIL→pin load/eval/state/compute; не расширять tolerances автоматически до observed instability.
3. Tensor inputs/schema/geometry FAIL→fix adapter+E002; all downstream comparisons повторить. Неверные classes/невидимый detail/QAT не исправит.
4. Preparation/export/pass/import FAIL→первый divergent parent, minimal operator probe; rollback pass/static shape/layout/endpoint. Не начинать calibration/QAT.
5. Float admitted, quant ref FAIL→effective settings/scope Q006, calib coverage/tails/weights-axis, one supported intervention. Exact stage не exposed→confounded declaration+GT gate, не выдуманная причина.
6. Quant ref good/device bad→Q008 codec/completion/target/preset/compiler; one QM parent, unchanged deployment outputs; train не первое средство.
7. Numeric/task near but NMS/events FAIL→common decoder thresholds/margins, actor/time/state/sampling; retuning dev другой policy, не чистый quantization repair.
8. Подтверждён quantitative loss и target consumer→bounded supported selective/bias/rounding/block reconstruction; далее QAT только при native/external contract proof E007 и measured resource pilot. Stop after accepted gates либо agreed rescue/trial limit; не “ещё вечер” без hypothesis.
9. Unsupported contract/model/operator→alternative **admission** Q016; model family/large float AP не rescue. New model reruns entire ladder. Vendor-ready artifact при реально выданном supported bundle — разумный первый device smoke, не equivalent custom solution.
10. Откат model+weights/config+preprocess+decoder/classes/skeleton+tracker/rules/zones/sampling/runtime compatible bundle; сохранить failed artifacts/logs/IDs, E012 review. Weight-only rollback недостаточен.

FullSDK может раскрыть most ladder, но не гарантирует float target/precision islands. RestrictedVM даёт доступные endpoints/trace; hidden stages not exposed после actual inventory, причинная attribution слабее. Catalog закрепляет service/model revision и complete inputs/results: без exact source checkpoint нельзя claim checkpoint fidelity, без device trace LinQ execution HOLD/attested separately. Во всех режимах quality can be measured to independent GT; scope не расширять из service label.
