## Decision and critic outcome

**K007: scope_narrowed.** The previously missing actual artifact/state contract is now established for two distinct official A0 Stream artifacts. Both have accessible bytes, a single named signature, matched external states and a reproducible static manifest. The INT8 variant also has an explicit model-instance Apache 2.0 field. Neither establishes a task-specific industrial hazard detector, onset/clear quality, CPU latency or actual LinQ execution. Keep MoViNet as a conditional generic video-classifier/training donor, not a ready hazard head. Engineering should start only if a relevant permissioned target sequence and SDK/device path justify comparison with simpler methods.

The most consequential finding is memory semantics: the head carries a cumulative feature sum and frame count across calls. Its score classifies the prefix since reset; it is not a sliding-window onset score. The original float artifact additionally carries cumulative squeeze/excitation pool states in its blocks. The INT8 artifact is a different modified architecture: 30 block pool-state input/output pairs are literal identity passthroughs, but the head pool remains active. A label or score at time t is not evidence of current hazard presence or timely clearance. No temporal behavior was measured.

## W2-07-F03 вЂ” pinned pooling, export and reset semantics

**primary_docs + static graph inference.** S03 source is contemporaneous with float storage upload but not a cryptographically linked build recipe. Its `export_saved_model.py` lines 163вЂ“195 builds explicit `image` and state signatures; `predict` returns states plus `logits`; bundled `init_states` is optional. The actual float and INT8 binaries expose only `serving_default`, no `init_states` callable. Initialize from actual signature shapes/dtypes, not by guessing an extra signature. Historical `modeling/movinet.py` defines slash-state names, including `state/bN/lN/...`; current S02 source uses underscore names and changed conventions. Current source must not silently replace the archived binary's contract.

Historical S04 `GlobalAveragePool3D` lines 637вЂ“681 reads a pool sum and frame counter, increments counter by frames in this call, adds spatially averaged current features to the sum, and divides by all frames since initialization. In causal mode it uses cumulative sums so each within-clip step sees only its prefix; in noncausal mode it aggregates the current call while retaining history. Head uses global pooling; block squeeze/excitation also uses cumulative pooling in float. This is feature averaging before classifier projection, not arithmetic averaging of class probabilities and not a fixed recent duration. Finite convolution stream buffers and global accumulators have different horizons.

Current pinned README lines 303вЂ“320 explicitly initializes all state tensors to zero, feeds returned states to the next frame and uses the last output as video classification. Its TFLite example lines 370вЂ“395 does the same. The model-page usage supplies the same zero-state/per-video loop. Documentation expresses a new-video boundary by creating/reassigning initial states before the video loop; no automatic camera/actor/PTS detection or timed reset is promised. In the chosen lifecycle contract a new independent video/camera stream/crop identity must receive fresh zero states. This boundary policy is our reproducible application choice grounded in the documented video-loop initialization, not an experimentally validated industrial reset cadence.

**inference:** retaining states after an event can retain features of the event, and a long normal prefix can dilute a later short event in head pooling. Resetting frequently can restore short horizon but changes the reference computation and repeatedly incurs cold-start history; no time-local detection guarantee follows. Refeeding an old frame updates counts again; dropped source time does not advance the network unless a frame is supplied. No source timestamp is an input, so changing cadence changes physical time represented by the same buffer length and frame average. Do not represent these models as PTS-aware temporal encoders.
