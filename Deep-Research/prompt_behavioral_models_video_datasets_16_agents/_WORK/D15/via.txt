              <h3>
                  <a href="https://www.robots.ox.ac.uk/~adutta/">Abhishek Dutta</a>,
                  <a href="https://www.robots.ox.ac.uk/~az/">Andrew Zisserman</a>,
                  <a href="https://www.robots.ox.ac.uk/~ankush/">Ankush Gupta</a>,
                  <a href="https://www.robots.ox.ac.uk/~pinto/">David Miguel Susano Pinto</a>,
                  <a href="https://www.robots.ox.ac.uk/~ecoto/">Ernesto Coto</a>,
                  Prasanna Sridhar,
                  <a href="https://ragavsachdeva.github.io/">Ragav Sachdeva</a>
              </h3>
              <br>

              <h3>Overview</h3>
              <p>
                VIA is a suite of tools for the annotation of image,
                audio, and audio files.  VIA tools are designed to be
                simple to use, and very lightweight.  They are web
                applications, distributed as single HTML files that
                run offline in a web browser, do not require
                installation or setup.  VIA is developed at
                the <a href="http://www.robots.ox.ac.uk/~vgg/">Visual
                Geometry Group (VGG)</a> and released under the
                permissive <a href="https://gitlab.com/vgg/via/blob/master/LICENSE">two-clause
                BSD license</a> which enables its use in both academic
                projects and commercial applications.
              </p>

              <p>
                Currently, VIA is comprised of the following tools:
              </p>

              <ul>
                <li>
                  <strong>VIA3</strong>
                  [<a href="#via3">webpage</a>]
                  [<a href="https://gitlab.com/vgg/via/-/tree/master/via-3.x.y">Gitlab</a>]

                  is the latest version of VIA "proper".  In addition
                  to images, it adds supports for video and audio
                  files, and shared/collaborative projects.
                </li>

                <li>
                  <strong>VIA2</strong>
                  [<a href="#via2">webpage</a>]
                  [<a href="https://gitlab.com/vgg/via/-/tree/master/via-2.x.y">Gitlab</a>]

                  is an older version of VIA.  Compared to VIA3, only
                  has support for image files and does not support
                  shared projects.  However, it has more features than
                  VIA3 and a different UI that some people prefer.
                  This version of VIA is still maintained.
                </li>

                <li>
                  <strong>LISA</strong> (LIS Annotator)
                  [<a href="#lisa">webpage</a>]
                  [<a href="https://gitlab.com/vgg/lisa">Gitlab</a>]

                  provides a simplified interface to efficiently
                  annotate a large list of images or videos.  It has
                  less features than VIA proper though.  The
                  simplified interface and reduced number of features
                  also makes the codebase simpler and so is simpler to
                  create variants of LISA.  Like VIA3, LISA has
                  support for shared projects.
                </li>

                <li>
                  <strong>VVT</strong> (VGG Visual Tracker)
                  [<a href="https://www.robots.ox.ac.uk/~vgg/software/vvt/">webpage</a>]
                  [<a href="https://gitlab.com/vgg/via/-/tree/add-tracking">Gitlab branch</a>]

                  is a modified version of VIA3 to annotate bounding
                  box video tracks with the assistance of a tracker.
                </li>

                <li>
                  <strong>SignDB</strong> Group Annotator
                  [<a href="https://www.robots.ox.ac.uk/~vgg/software/via/docs/signdb.html">webpage</a>]
                  [<a href="https://gitlab.com/vgg/via/-/tree/via3-group-annotator">Gitlab branch</a>]

                  is a variant of VIA3 to review and correct automatic
                  sign language spotting in video clips by grouping
                  them by the identified sign.
                </li>

                <li>
                  <strong>VASA</strong>
                  [<a href="https://www.robots.ox.ac.uk/~vgg/software/vasa/">webpage</a>]
                  [<a href="https://gitlab.com/vgg/vasa">Gitlab</a>]

                  is a variant of VIA2 augmented with searching
                  capabilities.
                </li>

                <li>
                  <strong>SUNO</strong> (SUrgeon's NOtebook)
                  [<a href="https://gitlab.com/vgg/suno">Gitlab</a>]

                  is a tool to manually annotate videos showing
                  surgical procedures.
                </li>

                <li>
                  <strong>LISA Manga</strong>
                  [<a href="https://gitlab.com/ragavsachdeva/lisa-manga/-/tree/manga">Gitlab</a>]
                  [<a href="https://meru.robots.ox.ac.uk/app/via/demo-gallery/lisa-graph-manga-diarisation/">Demo</a>]

                  is a variant of LISA to annotate and connect
                  characters and text boxes in manga pages.  It treats
                  bounding boxes as nodes of a graph and lines between
                  boxes as edges so could be used for other graph-like
                  annotations.
                </li>

                <li>
                  <strong>python-via</strong>
                  [<a href="https://pypi.org/project/python-via/">PyPI</a>]
                  [<a href="https://gitlab.com/vgg/python-via">Gitlab</a>]

                  is a Python package to handle VIA projects in
                  Python, namely to convert between different VIA
                  formats and COCO, and to download and upload shared
                  projects.
                </li>

                <li>
                  <strong>VFS</strong> (Version File Store)
                  [<a href="https://gitlab.com/vgg/vfs">Gitlab</a>]

                  is the service that enables shared projects in VIA
                  projects.  VGG maintains a public free instance of
                  VFS which VIA tools can use.  Unless you want to run
                  your own VFS, you won't need this for your shared
                  projects.
                </li>
              </ul>

            <h3>User Guide</h3>

            <p>A basic user guide is also available inside the VIA application and can be accessed using top menubar "Help -> Getting Started".                   <li><a href="./docs/creating_annotations.html">Creating Annotations</a></li>
                  <li>Importing and Exporting Annotations:
                    <ul class="ul-large">
                      <li>Click <code>Annotations &rarr; Export annotations</code> in top menubar (choose csv or json option)</li>
                      <li>Click <code>Annotations &rarr; Import annotations</code> in top menubar and select the file (csv or json) containing annotations.</li>
                    </ul>
                  </li>
                  <li>Saving and Loading a Project:
                    <ul>
                      <li>Click <code>Project &rarr; Save</code> in top menubar</li>
                      <li>Click <code>Project &rarr; Load</code> in top menubar and select the json file containing VIA project.</li>
                    </ul>
                  </li>

                <h3>Developer's Resources</h3>
                <p>VIA software is developed using HTML, CSS and Javascript and is based solely on standard features available in modern web browsers. VIA does not depend on any external libraries. These design decisions has helped us create a very light weight and feature rich manaul annotation software that can run on most modern web browsers without requiring any installation or setup. The full VIA software sprouted from an <a href="http://www.robots.ox.ac.uk/~vgg/software/via/via-0.0.1.txt" target="_blank">early prototype</a> of VIA which implemented a minimal -- yet functional -- image annotation tool using only 40 lines of HTML/CSS/Javascript code that runs as an offline application in most modern web browsers. This early prototype
            provides a springboard for understanding the current codebase of VIA which is just an extension of the early prototype. Furthermore, the <a href="https://developer.mozilla.org/en-US/docs/Web/HTML" target="_blank">introductory tutorials</a> prepared by Mozilla is also very helpful in understanding the basic concepts of HTML/CSS/Javascript platform.</p>

              <p>The VIA source code repository contains a separate folder for each major version of VIA: <a href="https://gitlab.com/vgg/via/blob/master/via-1.x.y/" target="_blank">via-1.x.y</a>, <a href="https://gitlab.com/vgg/via/blob/master/via-2.x.y/" target="_blank">via-2.x.y</a> and <a href="https://gitlab.com/vgg/via/blob/master/via-3.x.y/" target="_blank">via-3.x.y</a>.

                license.  The following code documentation are
                available for each major version of VIA:</p>
