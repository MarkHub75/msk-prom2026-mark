<p> 

 </p>



<p>The MediaPipe Pose Landmarker task lets you detect landmarks of human bodies in an image or
video. You can use this task to identify key body locations, analyze posture,
and categorize movements. This task uses machine learning (ML) models that
work with single images or video. The task outputs body pose landmarks in image
coordinates and in 3-dimensional world coordinates.</p>

<p>The code sample described in these instructions is available on
<a href="https://github.com/google-ai-edge/mediapipe-samples/tree/main/examples/pose_landmarker/python">GitHub</a>.
For more information about the capabilities, models, and configuration options
of this task, see the <a href="https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/index">Overview</a>.</p>

<h2 id="code_example" data-text="Code example" tabindex="-1">Code example</h2>

<p>The example code for Pose Landmarker provides a complete implementation of this
task in Python for your reference. This code helps you test this task and get
started on building your own pose landmarker. You can view, run, and
edit the
<a href="https://colab.research.google.com/github/googlesamples/mediapipe/blob/main/examples/pose_landmarker/python/%5BMediaPipe_Python_Tasks%5D_Pose_Landmarker.ipynb">Pose Landmarker example code</a>
using just your web browser.</p>

<p>If you are implementing the Pose Landmarker for Raspberry Pi, refer to the
<a href="https://github.com/google-ai-edge/mediapipe-samples/tree/main/examples/pose_landmarker/raspberry_pi">Raspberry Pi example
app</a>.</p>

<h2 id="setup" data-text="Setup" tabindex="-1">Setup</h2>

<p>This section describes key steps for setting up your development environment and
code projects specifically to use Pose Landmarker. For general information on
setting up your development environment for using MediaPipe tasks, including
platform version requirements, see the
<a href="/mediapipe/solutions/setup_python">Setup guide for Python</a>.</p>

<h3 id="packages" data-text="Packages" tabindex="-1">Packages</h3>

<p>The MediaPipe Pose Landmarker task requires the mediapipe PyPI package.
You can install and import these dependencies with the following:</p>

</code></pre></devsite-code>

<h3 id="model" data-text="Model" tabindex="-1">Model</h3>

<p>The MediaPipe Pose Landmarker task requires a trained model that is compatible with this
task. For more information on available trained models for Pose Landmarker, see

listener with the detection result every time it finishes processing an
input frame. If the detection function is called when the Pose Landmarker task
is busy processing another frame, the task will ignore the new input frame.</li>
</ul>

<p>For a complete example of running an Pose Landmarker on an image, see the
<a href="https://github.com/google-ai-edge/mediapipe-samples/tree/main/examples/pose_landmarker/python">code example</a>
for details.</p>

<h2 id="handle_and_display_results" data-text="Handle and display results" tabindex="-1">Handle and display results</h2>

<p>The Pose Landmarker returns a <code translate="no" dir="ltr">poseLandmarkerResult</code> object for each detection
run. The result object contains coordinates for each pose landmark.</p>

<p>The following shows an example of the output data from this task:</p>
<div></div><devsite-code><pre class="devsite-click-to-copy" translate="no" dir="ltr" is-upgraded><code translate="no" dir="ltr">PoseLandmarkerResult:
  Landmarks:
    Landmark #0:
      x            : 0.638852
      y            : 0.671197
      z            : 0.129959
      visibility   : 0.9999997615814209
      presence     : 0.9999984502792358
    Landmark #1:
      x            : 0.634599
      y            : 0.536441
      z            : -0.06984
      visibility   : 0.999909
      presence     : 0.999958
    ... (33 landmarks per pose)
  WorldLandmarks:
    Landmark #0:
      x            : 0.067485
      y            : 0.031084
      z            : 0.055223
      visibility   : 0.9999997615814209
      presence     : 0.9999984502792358
    Landmark #1:
      x            : 0.063209
      y            : -0.00382
      z            : 0.020920
      visibility   : 0.999976
      presence     : 0.999998
    ... (33 world landmarks per pose)
  SegmentationMasks:
    ... (pictured below)
</code></pre></devsite-code>
<p>The output contains both normalized coordinates (<code translate="no" dir="ltr">Landmarks</code>) and world
coordinates (<code translate="no" dir="ltr">WorldLandmarks</code>) for each landmark.</p>

<p>The output contains the following normalized coordinates (<code translate="no" dir="ltr">Landmarks</code>):</p>

<ul>
<li><p><code translate="no" dir="ltr">x</code> and <code translate="no" dir="ltr">y</code>: Landmark coordinates normalized between 0.0 and 1.0 by the
image width (<code translate="no" dir="ltr">x</code>) and height (<code translate="no" dir="ltr">y</code>).</p></li>
<li><p><code translate="no" dir="ltr">z</code>: The landmark depth, with the depth at the midpoint of the hips as the
origin. The smaller the value, the closer the landmark is to the camera. The
magnitude of z uses roughly the same scale as <code translate="no" dir="ltr">x</code>.</p></li>
<li><p><code translate="no" dir="ltr">visibility</code>: The likelihood of the landmark being visible within the image.</p></li>
</ul>

<p>The output contains the following world coordinates (<code translate="no" dir="ltr">WorldLandmarks</code>):</p>

<ul>
<li><p><code translate="no" dir="ltr">x</code>, <code translate="no" dir="ltr">y</code>, and <code translate="no" dir="ltr">z</code>: Real-world 3-dimensional coordinates in meters, with the
midpoint of the hips as the origin.</p></li>
<li><p><code translate="no" dir="ltr">visibility</code>: The likelihood of the landmark being visible within the image.</p></li>
</ul>

<p>The optional segmentation mask represents the likelihood of each pixel belonging
to a detected person. The following image is a segmentation mask of the
task output:</p>

<p><img src="/static/mediapipe/images/solutions/pose_detector_mask.png" alt="Segmentation mask of the previous image that outlines the shape of the woman" width="400px"> </p>

results returned from the task, see the
<a href="https://github.com/google-ai-edge/mediapipe-samples/tree/main/examples/pose_landmarker/python">code example</a>
for details.</p>
