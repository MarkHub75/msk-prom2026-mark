With .xlsx file of the experimental environment (SETTINGS OF THE COMBUSTION EXPERIMENT FOR DATA COLLECTION.xlsx), you can see the time of each data collection, so as to align the data.

The "xxxx-1" file in the physical data saves the specific time (min:sec ) of the collection, and the time is displayed in the upper left corner of the video data, and the corresponding sequence can be found. (The videos are raw surveillance data. )
