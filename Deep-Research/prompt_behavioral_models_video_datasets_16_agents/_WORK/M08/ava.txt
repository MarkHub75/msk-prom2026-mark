                <h2 class=>ActivityNet challenge ground truth release</h2>
            
        
        
    </div>



  <p data-block-key="oklnv">This download contains the ground truth labels for the previously held-out test sets used in the ActivityNet challenges for AVA Kinetics, AVA Actions, and AVA Active Speaker, as 3 files in the downloadable zipfile. They are formatted similarly to the previously released labeled data for each of the tasks.</p><p data-block-key="4vlt6">Download the challenge test set: <a href="https://x20web.corp.google.com/users/so/sourc/www/AVA-challenge-testset.zip" target="_blank" rel="noopener noreferrer"><b>AVA-challenge-testset.zip</b></a>.</p>

                <h2 class=>AVA-Kinetics download (v1.0)</h2>
            
        
        
    </div>



  <p data-block-key="6zh1t">The AVA-Kinetics dataset consists of the original 430 videos from AVA v2.2, together with 238k videos from the <a href="https://deepmind.com/research/open-source/kinetics" target="_blank" rel="noopener noreferrer">Kinetics-700 dataset</a>. For Kinetics we provide one annotated frame per video clip. The annotations are provided as CSV files, as described in the included README.txt file.</p><p data-block-key="cai9h">All of the annotation is provided in the in the .tar.gz file. Although there are separate CSV files for AVA and for Kinetics, it's expected that users will want to train / test on the union of the two.</p><p data-block-key="49pnh"></p><p data-block-key="1mo33">Download all AVA-Kinetics data: <a href="https://storage.googleapis.com/deepmind-media/Datasets/ava_kinetics_v1_0.tar.gz" target="_blank" rel="noopener noreferrer"><b>ava_kinetics_v1_0.tar.gz</b></a></p>

    <div class="component-intro ">
        
            
                <h2 class=>AVA Actions download (v2.2)</h2>
            
        
        
    </div>



  <p data-block-key="6zh1t">The AVA v2.2 dataset contains 430 videos split into 235 for training, 64 for validation, and 131 for test. Each video has 15 minutes annotated in 1 second intervals. The annotations are provided as CSV files:</p><ul><li data-block-key="6rc5k"><a href="https://research.google.com/ava/download/ava_train_v2.2.csv.zip"><b>ava_train_v2.2.csv (zip)</b></a> and <a href="https://research.google.com/ava/download/ava_val_v2.2.csv.zip"><b>ava_val_v2.2.csv (zip)</b></a>.</li></ul><p data-block-key="d60bs">For <a href="http://activity-net.org/challenges/2019/tasks/guest_ava.html" target="_blank" rel="noopener noreferrer"><b>Task B - Spatio-temporal Action Localization (AVA)</b></a> at the <a href="http://activity-net.org/challenges/2019/" target="_blank" rel="noopener noreferrer"><b>ActivityNet 2019 Challenge</b></a>, we're releasing the video ids for a set of 131 labeled test videos. The challenge will only evaluate performance on a subset of 60 classes. For details on how to submit your predictions on these videos please see the <a href="http://activity-net.org/challenges/2019/" target="_blank" rel="noopener noreferrer"><b>ActivityNet 2019 Challenge</b></a> page.</p><ul><li data-block-key="am7ke"><a href="https://research.google.com/ava/download/ava_test_v2.2.txt"><b>ava_test_v2.2.txt</b></a></li><li data-block-key="8mnut"><a href="https://research.google.com/ava/download/ava_action_list_v2.2_for_activitynet_2019.pbtxt"><b>ava_action_list_v2.2_for_activitynet_2019.pbtxt</b></a></li></ul><p data-block-key="b89o1">Generally raters provided annotations at timestamps 902:1798 inclusive, in seconds, at 1-second intervals. Performance is measured on all of these "included" timestamps, including those for which raters determined no action was present. For certain videos, some timestamps were excluded from annotation because raters marked the corresponding video clips as inappropriate. Performance is not measured on the "excluded" timestamps. The lists of included and excluded timestamps are:</p><ul><li data-block-key="8g1f5"><a href="https://research.google.com/ava/download/ava_included_timestamps_v2.2.txt"><b>ava_included_timestamps_v2.2.txt</b></a></li><li data-block-key="94p3v"><a href="https://research.google.com/ava/download/ava_train_excluded_timestamps_v2.2.csv"><b>ava_train_excluded_timestamps_v2.2.csv</b></a></li><li data-block-key="383ji"><a href="https://research.google.com/ava/download/ava_val_excluded_timestamps_v2.2.csv"><b>ava_val_excluded_timestamps_v2.2.csv</b></a></li><li data-block-key="bjjju"><a href="https://research.google.com/ava/download/ava_test_excluded_timestamps_v2.2.csv"><b>ava_test_excluded_timestamps_v2.2.csv</b></a></li></ul><p data-block-key="3s6hb"></p><p data-block-key="6k7eg">Download all AVA Actions data: <a href="https://research.google.com/ava/download/ava_v2.2.zip"><b>ava_v2.2.zip</b></a></p>

    <div class="component-intro ">
        
            
                <h3 class=>CSV format</h3>
            
        
        
    </div>



  <p data-block-key="6zh1t">Each row contains an annotation for one person performing an action in an interval, where that annotation is associated with the middle frame. Different persons and multiple action labels are described in separate rows.</p><p data-block-key="bhqd9">The format of a row is the following: video_id, middle_frame_timestamp, person_box, action_id, person_id</p><ul><li data-block-key="33ueo">video_id: YouTube identifier</li><li data-block-key="eg75g">middle_frame_timestamp: in seconds from the start of the YouTube.</li><li data-block-key="ff356">person_box: top-left (x1, y1) and bottom-right (x2,y2) normalized with respect to frame size, where (0.0, 0.0) corresponds to the top left, and (1.0, 1.0) corresponds to bottom right.</li><li data-block-key="4tv7g">action_id: identifier of an action class, see <a href="https://research.google.com/ava/download/ava_action_list_v2.2.pbtxt"><b>ava_action_list_v2.2.pbtxt</b></a></li><li data-block-key="dbiaa">person_id: a unique integer allowing this box to be linked to other boxes depicting the same person in adjacent frames of this video.</li></ul><p data-block-key="fkse2">AVA v2.2 differs from v2.1 in two ways. First another round of human rating was conducted to insert labels that were missing, increasing the number of annotations by 2.5%. Second, boxes locations were corrected for a small number of videos with aspect ratios much larger than 16:9.</p><p data-block-key="1e71c">AVA v2.1 differs from v2.0 only by the removal of a small number of movies that were determined to be duplicates. The class list and label map remain unchanged from v1.0.</p>
  
    
  
</div>

    <div class="component-intro ">
        
            
                <h3 class=>Pre-trained model</h3>
            
        
        
    </div>



  <p data-block-key="6zh1t">A pre-trained baseline model is also available. It was created using the <a href="https://github.com/tensorflow/models/tree/master/research/object_detection#tensorflow-object-detection-api" target="_blank" rel="noopener noreferrer">Tensorflow Object Detection API</a>.</p><p data-block-key="4djdt">The baseline model is an image-based Faster RCNN detector with ResNet-101 feature extractor. Compared with other commonly used object detectors, the action classification loss function has been changed to per-class sigmoid loss to handle boxes with multiple labels. The model was trained on the training split of AVA v2.1 for 1.5M iterations, and achieves mean AP of 11.25% over <a href="https://research.google.com/ava/download/ava_action_list_v2.2_for_activitynet_2019.pbtxt">60 classes</a> on the validation split of AVA v2.1.</p><p data-block-key="5afic">The model checkpoint can be obtained <a href="https://github.com/tensorflow/models/blob/master/research/object_detection/g3doc/tf1_detection_zoo.md#ava-v21-trained-models" target="_blank" rel="noopener noreferrer">here</a>. The predictions of this model on the AVA v2.1 validation split, in the CSV format described above, can be downloaded here: <a href="https://research.google.com/ava/download/ava_baseline_detections_val_v2.1.zip">ava_baseline_detections_val_v2.1.zip</a>.</p>
  
    
  
</div>

    <div class="component-intro ">
        
            
                <h2 class=>AVA Active Speaker download (v1.0)</h2>
            
        
        
    </div>



  <p data-block-key="6zh1t">Each zipped file contains a set of CSV files, one for each video in the [train/val] partition. The partitions are the same as AVA Actions.</p><p data-block-key="d78bp">For <a href="http://activity-net.org/challenges/2019/tasks/guest_ava.html" target="_blank" rel="noopener noreferrer"><b>Task B, Challenge #2- Active Speaker Detection</b></a> at the <a href="http://activity-net.org/challenges/2019/" target="_blank" rel="noopener noreferrer"><b>ActivityNet 2019 Challenge</b></a>, we're releasing data for 131 videos with <b>labels anonymized</b>. For details on how to submit your predictions on these videos, please see the information for Challenge #2 on the <a href="http://activity-net.org/challenges/2019/tasks/guest_ava.html" target="_blank" rel="noopener noreferrer"><b>ActivityNet 2019 Challenge: Task B</b></a> page.</p><ul><li data-block-key="eo7di"><a href="https://research.google.com/ava/download/ava_activespeaker_test_for_activitynet2019.tar.bz2"><b>ava_activespeaker_test_for_activitynet2019.tar.bz2</b></a></li></ul><p data-block-key="6urau">Each row in the CSV files contains an annotation for speaking activity associated with a single face for that frame. Different persons are described in separate rows. The format of a row is the following: video_id, frame_timestamp, entity_box, label, entity_id.</p><ul><li data-block-key="7b5pv">video_id: YouTube identifier</li><li data-block-key="661so">frame_timestamp: in seconds from the start of the video.</li><li data-block-key="3ieba">entity_box: top-left (x1, y1) and bottom-right (x2,y2) normalized with respect to frame size, where (0.0, 0.0) corresponds to the top left, and (1.0, 1.0) corresponds to bottom right.</li><li data-block-key="feabf">label: label for the entity specified at that frame.
