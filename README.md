# Argus — видеоконтроль промышленной безопасности на LinQ

Открой#Моспром 2026 · кейс ООО «ХайТэк» · инференс на российских ИИ-ускорителях LinQ.

Argus смотрит записи заводских камер, находит опасные ситуации с людьми и техникой и ведёт каждое нарушение от тревоги до записи в журнале: оператор видит доказательство и подтверждает его, мастер смены принимает меры с телефона, охрана труда получает журнал с фильтрами и отчётами. Пакет и CLI называются `safewatch` (рабочее имя до переименования продукта); переменные окружения — `SAFEWATCH_*`.

## Задача кейса

Постановщик просит сервис, который принимает видео производственных камер, распознаёт нейросетями опасное поведение людей и оперативно оповещает ответственных: кадр или клип, камера, время и тип нарушения, одно нарушение — одно оповещение. Нарушения сохраняются в журнале с фильтрами по типу, камере, зоне и времени. Инференс обязан выполняться на ускорителях LinQ с замером скорости. Сценарии кейса — бег у техники, опасное сближение с механизмами и транспортом, телефон в опасной ситуации, курение и открытый огонь, пересечение ограждений и проход под опасными конструкциями, работа на высоте без привязи, падение и неподвижность; команда выбирает приоритетные.

## Как это работает

```text
видео камеры
  → детекции людей и поз на LinQ (YOLOv8n 640, YOLOv8n-pose 640)
  → треки и эпизоды
  → правило сцены по зонам и линиям камеры
  → одно событие: кадр, клип, камера, время, тип, «почему»
  → оповещение оператору (WebSocket, захват экрана, сирена)
  → подтверждение оператором → поручение мастеру → меры → «Решено»
  → журнал охраны труда, статистика, CSV и PDF
```

| Роль | Что делает |
|---|---|
| Оператор | диспетчерская по секторам, монитор камеры с HUD и зонами, очередь тревог; подтверждает событие или отклоняет как ложное |
| Мастер смены | на телефоне: «Принял, иду» → «Принятые меры» → «Решено» |
| Охрана труда | журнал с фильтрами, CSV и PDF, правила и зоны по камерам, статистика |
| Руководство | аналитика по неделям, калькулятор окупаемости |
| Администратор | камеры и секторы, видео, калибровка, зоны, правила; «Система» с бэкендом инференса и замерами LinQ; демо-пульт |

Архитектура: бэкенд на Python 3.12, FastAPI и SQLite (видео, задачи анализа, адаптер LinQ, правила, эпизоды, события, WebSocket); фронт на React и Vite, тексты на русском. Docker собирает фронт и отдаёт его вместе с API и WebSocket на порту 8000.

## Запуск в Docker

Нужен Docker Desktop с Linux containers или Docker Engine, Compose **2.24+**, свободный порт 8000 и запас места на диске Docker. Python и Node на хосте не нужны.

1. Клонируйте репозиторий и перейдите в корень:

   ```text
   git clone https://github.com/MarkHub75/msk-prom2026-mark.git
   cd msk-prom2026-mark
   ```

2. Скачайте из [релиза `demo-argus-real`](https://github.com/MarkHub75/msk-prom2026-mark/releases/tag/demo-argus-real) архив `argus-real-v2.zip` и распакуйте его в `data/demo/`. В архиве уже есть корневая папка, поэтому должен появиться файл `data/demo/argus-real-v2/manifest.json`, рядом `videos/`, `artifacts/` и `ATTRIBUTION.txt`.
3. Скопируйте `config/docker.example.yaml` в `config/user.yaml` (UTF-8 без BOM). Профиль уже указывает на `data/demo/argus-real-v2`; пути в нём — пути внутри контейнера.
4. Соберите и запустите:

   ```text
   docker compose up -d --build
   docker compose ps
   ```

5. Откройте `http://127.0.0.1:8000/?review=real`. Пакет импортирован, если `/api/demo/packs` показывает `argus-real-v2`, `backend: "linq"`, `fake: false`, четыре камеры и четыре видео.

Для показа из пакета `.env`, ключи LinQ и VPN не нужны: детекции заранее посчитаны на LinQ и воспроизводятся из кэша. База живёт в именованном томе Docker и переживает `restart` и `down`/`up`. Запасной пакет, смена пакета на свежей базе, Tuna, диагностика и ограничения — в [docs/DEPLOY.md](docs/DEPLOY.md).

## LinQ: что исполняется и что измерено

Детектор YOLOv8n 640 и поза YOLOv8n-pose 640 скомпилированы в программы `.tpu` и исполняются на LinQ; постобработка — ONNX-хвосты на CPU сервера. Видео обрабатывается внутри LinQ Jupyter, доступ — через SSH-туннель. Площадка общая для команд хакатона, поэтому RTT включает очередь и сеть, а не только ускоритель.

| Режим | Что происходит | Где виден |
|---|---|---|
| Новая обработка на LinQ | видео уходит в LinQ Jupyter, детекции считает TPU | `INFERENCE_BACKEND=linq`, нужны ключи `LINQ_*` |
| Воспроизведение демо-пакета | детекции, ранее посчитанные на LinQ, берутся из кэша; это не новый замер TPU | метрики задачи `cached: true` |
| Локальный CPU | тот же YOLOv8n в onnxruntime | `INFERENCE_BACKEND=local` |
| Синтетика для разработки | рамки сгенерированы и не обязаны совпадать с людьми | `SAFEWATCH_FAKE=1`, интерфейс подписывает «Демо · синтетические детекции» |

Живые прогоны на LinQ (общая очередь, `--inflight 4`):

| Прогон | Результат | Источник |
|---|---|---|
| 24.10 14:52, проверка адаптера, 400 кадров | детектор ~12,4 кадр/с, поза ~12,7 кадр/с, RTT p50/p90 ~290/~380 мс | [tech.md](tech.md), раздел 2 |
| 25.10 00:00, сквозная цепочка на реальной сцене (20,8 с, 1920×1080) | 261 из 261 кадра, 7,8 кадр/с, RTT p50 434 мс, красное событие на 16,3 с | [progress.md](progress.md), S28 |
| 25.10 01:25, сборка пакета `argus-real`, 598 кадров | детектор 10,6 кадр/с, поза 10,5 кадр/с, RTT p50 297–331 мс, p90 415–454 мс | [progress.md](progress.md), R32 |

Камеры 1.4 и 1.5 пакета v2 посчитаны на LinQ 25.10 в 04:14 МСК теми же моделями. Компиляция, квантование и сверка с CPU — [docs/linq/STATUS.md](docs/linq/STATUS.md) и [results/linq_smoke/](results/linq_smoke/); факты о платформе — [docs/linq/LINQ_CONTRACT.md](docs/linq/LINQ_CONTRACT.md). Производительность выделенного ускорителя по данным вендора нашим замером не является.

## Разработка без Docker

Python 3.12, [uv](https://docs.astral.sh/uv/), Node 24:

```text
uv sync --locked
npm ci --prefix frontend
npm run build --prefix frontend
uv run --no-sync safewatch serve --seed
```

Остановка host-сервера: `uv run --no-sync safewatch stop`; не запускайте его одновременно с Docker на порту 8000. Проверки: `uv run poe gate` (линтер, типы, тесты бэкенда, контракт, фронт). Режимы фронта — [frontend/README.md](frontend/README.md). Оценка качества на размеченных видео — `uv run safewatch eval config/eval.example.yaml`, подключение моделей — [docs/ML_INTEGRATION.md](docs/ML_INTEGRATION.md).
